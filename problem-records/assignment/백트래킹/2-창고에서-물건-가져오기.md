## 문제 요약

N개 상자에 각각 K개 물건이 위에서부터 순서대로 쌓여 있다.
각 상자에서는 위에 있는 물건부터 꺼내야 한다.
전체에서 정확히 P개를 꺼내 얻을 수 있는 최대 가치 합을 구한다.

## 입출력

- 입력: 첫 줄 N K P, 이후 N줄에 각 상자의 물건 가치 K개가 위에서부터 주어진다.
- 출력: 정확히 P개를 꺼냈을 때 최대 가치 합.
- 범위: N≤50, K≤30, P≤N×K, 각 가치 1..100.
- 제공 제한에는 T≤50이 있으나 입력 설명에 T가 없어 현재 환경은 단일 테스트 입력으로 세팅했다.

### 예제 입력

```text
2 4 5
10 10 100 30
80 50 10 50
```

### 예제 출력

```text
250
```

- 두 번째 제공 예제: N=3, K=2, P=3, 상자별 [80,80], [15,50], [20,10] → 180.

## 기록 시점 Main 코드 (미해결)

사용자가 Main에서 직접 풀이한 요청에 따라 Solution 대신 Main 전체를 원형대로 보존한다.

```java
import java.io.*;
import java.util.*;

public class Main {
    static Map<Integer, Integer> map = new HashMap<>();
    static Deque<Integer>[] boxes;
    static int answer = 0;
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        // 상자 개수
        int N = Integer.parseInt(st.nextToken());
        // 각 상자 물건 개수
        int K = Integer.parseInt(st.nextToken());
        // 꺼낼 물건 수
        int P = Integer.parseInt(st.nextToken());

        // 각 상자 안에 들어있는 물건들의 가치
        boxes = new ArrayDeque[N];
        for(int i = 0; i < N; i++){
            boxes[i] = new ArrayDeque<>();
        }
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < K; j++) {
                boxes[i].add(Integer.parseInt(st.nextToken()));
                map.put(i, map.getOrDefault(i, 0) + 1);
            }
        }

        backtracking(P, 0, N, 0);
        System.out.println(answer);

    }

    static void backtracking(int target, int cnt, int N, int sum){
        if(cnt == target){
            answer = Math.max(answer, sum);
            return;
        }

        for(int i = 0; i < N; i++){
            if(map.get(i) == 0) continue;
            int price = boxes[i].pollFirst();
            map.put(i, map.get(i) - 1);
            backtracking(target, cnt + 1, N, sum + price);
            boxes[i].addFirst(price);
            map.put(i, map.get(i) + 1);
        }
    }
}
```

## 처음 접근

각 상자를 Deque로 만들고 남은 물건 수를 Map으로 관리했다.
매 단계에서 하나의 상자를 골라 맨 위 물건을 꺼내고, 재귀 호출 후 복구한다.
P개를 꺼냈을 때 가치 합의 최댓값을 갱신한다.

사용자가 static 변수·메서드 관련 도움을 받은 뒤 백트래킹 구현을 완성했다.

## 핵심 아이디어 (해설 학습용)

1. 상자에서 x개를 꺼내면 맨 위 x개로 선택이 정해진다.
2. prefix[i][x]에 i번 상자의 맨 위 x개 가치 합을 저장한다. prefix[i][0]=0.
3. dp[i][j]를 앞의 i개 상자에서 정확히 j개를 꺼냈을 때의 최대 가치로 정의한다.
4. i번째 상자에서 x개를 꺼내면 나머지 j-x개는 앞의 i-1개 상자에서 가져온다.

점화식:

```text
dp[i][j] = max(dp[i-1][j-x] + prefix[i][x])
           (0 ≤ x ≤ min(K,j), 이전 상태가 가능한 경우)
```

초기값은 dp[0][0]=0, 나머지는 -1(불가능)이다. 모든 가치가 양수이므로 -1을 표시값으로 사용할 수 있다.
정답은 dp[N][P]. 이전 선택 이력에 관계없이 앞의 i개 상자를 끝내고 j개를 고른 상태에서는
이후 상자에 대한 선택 가능성이 같으므로 최대 가치 하나만 유지하면 된다.

예제 1에서 두 번째 상자로부터 꺼내는 개수 x를 비교하면:

| x | 첫 상자에서 꺼낼 개수 | 합계 |
|---|---|---|
| 0 | 5 | 불가능 |
| 1 | 4 | 150 + 80 = 230 |
| 2 | 3 | 120 + 130 = 250 |
| 3 | 2 | 20 + 140 = 160 |
| 4 | 1 | 10 + 190 = 200 |

최대는 250이다.

## 복잡도

- 기존 코드: 각 단계에서 최대 N개로 분기하고 깊이는 P. N≥2일 때 탐색 시간 상한 O(N^P), N=1이면 O(P). 비어 있는 상자는 제외되므로 실제 분기 수는 이 상한보다 작을 수 있다.
- 기존 공간: 상자 저장 O(NK), 재귀 깊이 O(P), Map O(N). 전체 O(NK+P).
- 해설 DP 시간: O(NPK), 단일 테스트 최대 약 225만 번의 전이 후보 확인.
- 해설 DP 공간: 2차원 DP와 누적 합 저장 시 O(NP+NK).

## 반례와 경계 조건

- 최소 입력: N=K=P=1.
- 전체 선택: P=N×K.
- 하나 선택: P=1.
- 아래쪽에 높은 가치가 있어도 그 위 물건을 함께 선택해야 한다.
- 정확히 P개 조건을 지키기 위해 불가능한 DP 상태를 구분한다.
- 최대 가치 합은 1500×100=150000으로 int 범위 안이다.
- 검증: 제공 예제 2개, 추가 경계 4개, 작은 범위 전수 64개, 무작위 60개 통과. 성능 입력 2개 실패.
