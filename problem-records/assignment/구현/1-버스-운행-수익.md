## 문제 요약

줄에 선 일행을 순서대로 버스에 태워 R회 운행한다. 일행은 나눌 수 없으며,
다음 일행을 태우면 정원을 넘는 경우 탑승을 마친다. 한 운행에 각 일행은 최대 한 번 탑승한다.
탑승한 일행은 순서대로 줄 뒤에 합류한다. 1명당 1유로인 총 수익을 구한다.

## 입출력

- 입력: 첫 줄 R K N, 둘째 줄 일행별 인원 N개.
- 범위: 1 ≤ R ≤ 1,000,000, 1 ≤ K ≤ 10,000, 1 ≤ N ≤ 100, 1 ≤ gᵢ ≤ K.
- 출력: R회 운행의 총 수익.

### 예제 입력

```text
4 6 4
1 4 2 1
```

### 예제 출력

```text
21
```

- 추가 제공 예제: `3 5 4 / 2 3 1 2` → `14`
- 추가 제공 예제: `5 10 3 / 4 3 2` → `45`

## 최종 Main 코드

아래는 사용자 요청에 따라 코드 전체를 주석·공백·서식을 변경하지 않고 복사한 것이다.
로컬 확장 채점을 통과했으며 온라인 정답 여부는 확인되지 않았다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        // 운행횟수
        int R = Integer.parseInt(st.nextToken());
        // 최대 탑승인원
        int K = Integer.parseInt(st.nextToken());
        // 줄을 이루는 수
        int N = Integer.parseInt(st.nextToken());

        // 줄
        int[] groups = new int[N];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < N; i++) {
            groups[i] = Integer.parseInt(st.nextToken());
        }

        // 대기 줄 큐
        Queue<Integer> ready = new LinkedList<>();
        // 버스 안 큐
        Queue<Integer> bus = new LinkedList<>();
        // 탑승자 수
        int people = 0;
        // 수익
        long answer = 0;
        // 초기화
        for(int i = 0; i < groups.length; i++){
            ready.add(groups[i]);
        }
        for(int i = 0; i < R; i++){
            while(people < K){
                if(ready.isEmpty() || ready.peek() + people > K){
                    break;
                }
                int count = ready.poll();
                people += count;
                answer += count;
                bus.add(count);
            }
            people = 0;
            while(!bus.isEmpty()){
                ready.add(bus.poll());
            }
        }
        System.out.println(answer);
    }

}
```

## 처음 접근

최초 확인 코드 기준으로 대기 줄과 버스 내부를 각각 큐로 관리하며 운행을 순서대로 수행했다.
사용자가 별도로 설명한 접근 과정은 기록되지 않았다.

## 처음 틀렸던 점

- 최초 채점은 컴파일 오류로 실행되지 않았다.
- 당시 코드의 확인된 부분:

```java
for(int i = 0; i M groups.length; i++){
```

- 당시 `System.out.println(answer);`는 main 메서드 바깥에 있었다.
- 이후 확장 테스트에서 누적 수익의 int 범위 초과로 2개 실패했다.
- 당시 누적 수익 선언:

```java
int answer = 0;
```

- 실제 반례: `R=1000000, K=10000, N=1, groups=[10000]`, 기댓값 `10000000000`, 실제값 `1410065408`.
- 사용자가 오버플로우 가능성을 짚고 long으로 수정했다.

## 수정 과정

현재 코드에서는 반복문 조건이 `<`로 작성되어 있고 출력문이 main 내부에 있다.
탑승 반복문의 종료 조건에 `ready.isEmpty()`도 추가되어 있다.
사용자가 별도 프로젝트에서 수정한 후 예제 1~3 통과를 알렸으며,
최초 기록 시점의 Main도 컴파일 및 제공 예제 3개를 통과했다.
추가 채점에서 160개 중 2개가 실패했고, 사용자가 answer를 long으로 수정한 뒤 재채점 328개를 모두 통과했다.

## 핵심 아이디어

현재 코드의 동작은 대기 큐에서 탑승 가능한 일행을 버스 큐로 옮기고,
운행이 끝나면 버스 큐의 일행을 순서대로 대기 큐 뒤에 붙이는 것이다.

## 복잡도

- 시간 복잡도: O(R × N), 각 운행에서 최대 N개 일행을 처리한다.
- 공간 복잡도: O(N), 인원 배열과 두 큐를 사용한다.

## 반례와 경계 조건

- 최소 입력: R=1, K=1, N=1, g₁=1.
- 최대 입력: R=1,000,000, K=10,000, N=100.
- 확인할 형태: 정원과 탑승 인원이 같은 경우, 전체 일행이 한 번에 탑승하는 경우, 다음 일행이 정원을 초과하는 경우.
- 누적 수익은 최대 100억이므로 long으로 저장한다.
- 검증 범위: 제공 예제 3개, 추가·경계·성능 7개, 고정 시드 무작위 150개, 작은 범위 전수 168개. 별도 검증 구현과 대조하여 총 328개 통과.
- 작은 범위 전수: K=1..3, N=1..3의 모든 일행 배열과 R∈{1,2,7}.
- 최대 운행·일행수 사례 실행 시간: 약 1.011초 (로컬 JVM 시작 포함, -Xmx256m).
- 공식 시간 제한은 미제공이므로 온라인 실행 시간 충족 여부는 확정하지 않는다.
- 제출 파일은 별도 컴파일 후 예제 3개 및 핵심 추가·경계·성능 7개를 재검증했다.
