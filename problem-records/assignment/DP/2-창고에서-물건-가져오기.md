## 문제 요약

N개 상자에 각각 K개 물건이 위에서부터 순서대로 쌓여 있다.
각 상자에서는 위에서부터 꺼내야 하며 전체에서 정확히 P개를 꺼낼 때 최대 가치 합을 구한다.

## 입출력

- 입력: 첫 줄 N K P, 이후 N줄에 각 상자의 물건 가치 K개.
- 범위: 1≤N≤50, 1≤K≤30, 1≤P≤N×K, 1≤가치≤100.
- 출력: 정확히 P개를 꺼냈을 때 최대 가치 합.
- 제공 제한에 T≤50이 있지만 입력 설명과 예제에는 T가 없어, 기존 환경과 제출 파일 모두 T 없는 단일 테스트 형식이다.

### 예제 입력

```text
2 4 5
10 10 100 30
80 50 10 50
```

### 예제 출력

```text
250
```

## 최종 Solution 코드

이 과제는 사용자가 `assignments/02-warehouse/Main.java`에서 직접 풀이하는 형식이므로,
별도 Solution.java 대신 해당 연습 코드 전체를 원형 그대로 보존한다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        // 상자 개수
        int N = Integer.parseInt(st.nextToken());
        // 각 상자 물건 개수
        int K = Integer.parseInt(st.nextToken());
        // 꺼낼 물건 수
        int P = Integer.parseInt(st.nextToken());

        // 각 상자 안에 들어있는 물건들의 누적합 (1개 집을때값, 2개집을때값)
        int[][] boxes = new int[N+1][K+1];
        for(int i = 1; i < N+1; i++){
            st = new StringTokenizer(br.readLine());
            for(int j = 1; j < K+1; j++){
                boxes[i][j] = Integer.parseInt(st.nextToken()) + boxes[i][j-1];
            }
        }

        // 꺼낼 개수
        int pick = Math.min(K,P);

        // dp 초기화 dp[i][i] = 앞의 i개의 상자에서 j를 선택했을때 최대값
        int[][] dp = new int[N + 1][P + 1];
        for(int i = 0; i < N + 1; i++){
            for(int j = 0; j < dp[0].length; j++){
                dp[i][j] = Integer.MIN_VALUE;
            }
        }
        dp[0][0] = 0;

        // 점화식 - dp[i][j] = max(dp[i][j], dp[i-1][j-k] + boxes[i][k])
        for(int i = 1; i < N + 1; i++){
            for(int j = 0; j <= P; j++){
                // 꺼낼 수가 상자 내용물 개수보다 많을 수 있으니
                for(int m = 0; m <= Math.min(j,pick); m++){
                    if(dp[i-1][j-m] == Integer.MIN_VALUE) continue;
                    dp[i][j] = Math.max(dp[i][j], dp[i-1][j-m] + boxes[i][m]);
                }
            }
        }

        System.out.println(dp[N][P]);
    }

}
```

## 처음 접근

상자를 Deque로 관리하고 물건을 하나 꺼낼 때마다 상자를 선택하는 백트래킹으로 풀었다.
이후 DP 해설을 학습하고, 상태의 행·열 의미와 불가능한 상태의 초기화를 확인한 뒤 직접 구현했다.

## 처음 틀렸던 점

- 최초 백트래킹은 큰 입력에서 로컬 10초 제한을 초과했다. 동일한 선택을 꺼내는 순서별로 반복 탐색했다.
- 과거 성능 실패: N=2, K=15, P=30, 모든 가치 1 (기댓값 30); N=50, K=30, P=1500, 모든 가치 1 (기댓값 1500).
- 당시 코드 원문:

```java
import java.io.*;
import java.util.*;

public class Main {
    static Map<Integer, Integer> map = new HashMap<>();
    static Deque<Integer>[] boxes;
    static int answer = 0;
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());
        // 상자 개수
        int N = Integer.parseInt(st.nextToken());
        // 각 상자 물건 개수
        int K = Integer.parseInt(st.nextToken());
        // 꺼낼 물건 수
        int P = Integer.parseInt(st.nextToken());

        // 각 상자 안에 들어있는 물건들의 가치
        boxes = new ArrayDeque[N];
        for(int i = 0; i < N; i++){
            boxes[i] = new ArrayDeque<>();
        }
        for (int i = 0; i < N; i++) {
            st = new StringTokenizer(br.readLine());
            for (int j = 0; j < K; j++) {
                boxes[i].add(Integer.parseInt(st.nextToken()));
                map.put(i, map.getOrDefault(i, 0) + 1);
            }
        }

        backtracking(P, 0, N, 0);
        System.out.println(answer);

    }

    static void backtracking(int target, int cnt, int N, int sum){
        if(cnt == target){
            answer = Math.max(answer, sum);
            return;
        }

        for(int i = 0; i < N; i++){
            if(map.get(i) == 0) continue;
            int price = boxes[i].pollFirst();
            map.put(i, map.get(i) - 1);
            backtracking(target, cnt + 1, N, sum + price);
            boxes[i].addFirst(price);
            map.put(i, map.get(i) + 1);
        }
    }
}
```

- DP 구현 후 첫 채점에서는 아래 출력문이 포함되어 제공 예제 2개와 최소 입력의 전체 출력 비교에 실패했다.

```java
        System.out.println(Arrays.deepToString(dp));
        System.out.println(dp[N][P]);
```

## 수정 과정

1. 상자를 하나씩 처리하는 DP로 사용자가 직접 재구현했다.
2. `dp[i][0]`은 0개 선택의 가치 0이고, `dp[0][j]`는 j>0에서 불가능하다는 의미를 확인했다.
3. `dp[0][0]=0`에서 첫 행을 만들며, 불가능한 이전 상태는 전이에서 제외하도록 작성했다.
4. 첫 채점 뒤 사용자가 중간 배열 출력문을 제거했다.
5. 수정된 원본을 변경하지 않고 223개 테스트를 채점해 모두 통과했다.

## 핵심 아이디어

- `boxes[i][m]`은 i번째 상자 위에서부터 m개를 꺼냈을 때의 누적 가치다.
- `dp[i][j]`는 앞의 i개 상자에서 정확히 j개를 꺼냈을 때 최대 가치다.
- i번째 상자에서 m개를 꺼내는 모든 경우에 대해 `dp[i-1][j-m] + boxes[i][m]`의 최댓값을 취한다.
- 이전 행만 참조하므로 현재 상자를 중복 사용하지 않는다.
- 모든 상태를 `Integer.MIN_VALUE`로 초기화하고 `dp[0][0]=0`으로 둔다. 불가능한 상태에는 덧셈하지 않는다.
- 답은 `dp[N][P]`이다.

## 복잡도

- 시간 복잡도: O(N×P×min(K,P)), 최악 O(NPK).
- 공간 복잡도: O(NP+NK).

## 반례와 경계 조건

- N=K=P=1, 상자 하나, K=1, P=1, P=N×K.
- 아래쪽에 큰 가치가 있는 상자, 한 상자에서 전부 선택하거나 특정 상자를 사용하지 않는 경우.
- K보다 작거나 큰 P, 모두 같은 가치, 최대 가치 합 150000.
- 작은 범위 전수 82개, 무작위 100개 (고정 seed 20261006), 추가 경계 18개, 단일 상자 3개, 과거 실패 1개, 최대 크기 17개, 제공 예제 2개를 통과했다.
