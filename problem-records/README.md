## 기록 규칙

- 플랫폼별 폴더 아래에서 최종 풀이의 주 알고리즘별 하위 폴더에 Markdown 파일로 저장합니다.
- 여러 알고리즘이 섞인 문제는 정답을 결정하는 핵심 알고리즘을 기준으로 분류합니다.
- 파일 이름은 `<문제번호>-<한글-문제명>.md` 형식을 사용합니다.
- 온라인 정답 확인, 로컬 확장 채점 통과 또는 사용자 기록 요청 시 작성하며, 확인된 상태를 구분해 표시합니다.
- 새 기록은 [TEMPLATE.md](./TEMPLATE.md)를 기준으로 작성합니다.
