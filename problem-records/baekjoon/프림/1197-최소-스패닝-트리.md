# 백준 1197 - 최소 스패닝 트리

## 문제 정보

- 플랫폼: 백준 온라인 저지
- 문제 번호: 1197
- 난이도: 골드 IV (solved.ac, 2026-08-04 확인)
- 문제 링크: https://www.acmicpc.net/problem/1197
- 풀이 날짜: 2026-08-03
- 결과: 정답
- 검증: 로컬 확장 채점 전체 통과 및 백준 반례 찾기 사이트에서 반례 미발견
- 비고: 백준 채점 서비스를 이용할 수 없어 실제 온라인 제출 결과는 확인하지 못함

## 문제 요약

가중치가 있는 연결된 무방향 그래프가 주어진다. 모든 정점을 연결하면서 선택한
간선 가중치의 합이 최소가 되는 스패닝 트리의 가중치 합을 구한다.

## 입출력

- 입력: 정점 수 `V`, 간선 수 `E`에 이어 `E`개의 간선 `A B C`가 주어진다.
- 출력: 최소 스패닝 트리의 가중치 합을 출력한다.

연습 템플릿에서는 다음 함수 형태로 변환했다.

```java
public long solution(int vertexCount, int[][] edges)
```

## 최종 코드

```java
import java.util.*;

public class Solution {
    class Node {
        int next;
        int weight;

        public Node(int next, int weight) {
            this.next = next;
            this.weight = weight;
        }
    }

    List<Node>[] graph;
    int[] dp;

    public long solution(int vertexCount, int[][] edges) {
        dp = new int[vertexCount + 1];
        graph = new ArrayList[vertexCount + 1];
        for (int i = 0; i < vertexCount + 1; i++) {
            graph[i] = new ArrayList<>();
        }

        for (int[] edge : edges) {
            int start = edge[0];
            int end = edge[1];
            int weight = edge[2];

            graph[start].add(new Node(end, weight));
            graph[end].add(new Node(start, weight));
        }

        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[1] = 0;
        boolean[] visited = new boolean[vertexCount + 1];

        PriorityQueue<Node> pq =
                new PriorityQueue<>((a, b) -> Integer.compare(a.weight, b.weight));
        pq.add(new Node(1, 0));

        long answer = 0L;
        while (!pq.isEmpty()) {
            Node node = pq.poll();
            int curr = node.next;
            if (visited[curr]) continue;

            visited[curr] = true;
            answer += node.weight;

            for (int i = 0; i < graph[curr].size(); i++) {
                Node nextNode = graph[curr].get(i);
                int next = nextNode.next;
                int nextWeight = nextNode.weight;
                if (!visited[next] && dp[next] > nextWeight) {
                    dp[next] = nextWeight;
                    pq.add(new Node(next, dp[next]));
                }
            }
        }

        return answer;
    }
}
```

## 처음 접근

인접 리스트로 무방향 그래프를 구성하고, 1번 정점부터 시작해 아직 방문하지 않은
정점으로 연결되는 간선 중 선택 가능한 가중치를 `dp`에 저장했다. 우선순위 큐에서
정점을 하나씩 꺼내 방문 처리하고 `dp`의 합을 반환하는 방식으로 프림 알고리즘을
구현하려고 했다.

## 처음 틀렸던 점

- 틀린 원인: 첫 구현의 우선순위 큐가 간선 가중치가 아닌 정점 번호를 기준으로 정렬됐다.
- 놓친 조건: 다음 정점은 번호가 아니라 현재 연결 가능한 간선의 최소 가중치를 기준으로
  선택되어야 한다.
- 당시 핵심 코드:

```java
PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.add(1);

int curr = pq.poll();
```

다음 테스트에서 처음 구현은 실패했다.

```text
입력
3 3
1 2 10
1 3 1
3 2 1

기댓값: 2
실제값: 11
```

## 수정 과정

우선순위 큐의 원소를 정점 번호만 담는 `Integer`에서 정점과 가중치를 함께 담는
`Node`로 변경했다. 비교 기준을 `Node.weight`로 지정하고, 큐에서 꺼낸 간선의
가중치를 정점이 처음 확정되는 시점에 정답에 더하도록 수정했다.

수정 후 공식 예제, 이전 실패 사례, 음수 가중치, 평행 간선, 큰 가중치 합,
무작위 그래프 300개를 모두 통과했다. 정점 10,000개와 간선 100,000개로 구성한
성능 테스트도 통과했다. 이후 사용자가 백준 반례 찾기 사이트에서도 검사했으며
추가 반례가 발견되지 않아 정답으로 기록했다.

## 핵심 아이디어

- 각 정점에 인접한 간선을 인접 리스트에 저장한다.
- 방문하지 않은 정점으로 이어지는 후보 간선을 우선순위 큐에 넣는다.
- 큐는 정점 번호가 아닌 간선 가중치가 작은 순서로 꺼낸다.
- 이미 방문한 정점으로 향하는 큐 원소는 건너뛴다.
- 정점이 처음 방문될 때 사용된 간선의 가중치를 정답에 더한다.
- 전체 합은 `int` 범위를 벗어날 수 있으므로 `long`으로 관리한다.

## 복잡도

- 시간 복잡도: `O(E log E)`
- 공간 복잡도: `O(V + E)`

## 반례와 경계 조건

- 정점이 하나이고 간선이 없는 경우
- 간선 가중치가 음수인 경우
- 같은 두 정점 사이에 여러 간선이 존재하는 경우
- 정점 번호가 작은 간선보다 정점 번호가 큰 간선의 가중치가 더 작은 경우
- 오래된 가중치 후보가 우선순위 큐에 남아 있는 경우
- 최소 스패닝 트리의 최종 가중치 합이 `int` 범위를 벗어나는 경우

## 한 줄 요약

프림의 우선순위 큐는 정점 번호가 아니라 현재 연결 후보의 **간선 가중치**를 기준으로 정렬한다.
