## 문제 요약

0은 이동 가능한 칸, 1은 벽인 N×M 지도에서 (1, 1)부터 (N, M)까지 이동한다.
상하좌우로 이동하며 벽은 최대 한 개까지 부술 수 있다. 시작과 끝 칸을 포함한 최단 경로의 칸 수를 구한다.

## 입출력

- 입력: N, M (각 1 이상 1000 이하), 이어서 N줄에 M자리의 0·1 문자열이 공백 없이 주어진다. 시작점과 도착점은 항상 0이다.
- 출력: 최단 경로의 칸 수. 도착할 수 없으면 -1.
- 공식 예제 전체: `examples/baekjoon/2206/`.

### 예제 입력

```text
0100

0000

0000
```

## 최종 Main 코드

사용자가 작성한 `src/Main.java` 전체를 원형 그대로 보존한다.

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;

public class Main {
    static int N;
    static int M;
    static int[] dxs = {1,0,-1,0};
    static int[] dys = {0,1,0,-1};
    static class Node{
        int x;
        int y;
        int used;
        int cnt;

        Node(int x, int y, int used, int cnt){
            this.x = x;
            this.y = y;
            this.used = used;
            this.cnt = cnt;
        }
    }
    public static void main(String[] args) throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(bf.readLine());

        N = Integer.parseInt(st.nextToken());
        M = Integer.parseInt(st.nextToken());

        int[][] grid = new int[N][M];
        for(int i = 0; i < N; i++){
            String[] arr = bf.readLine().split("");
            for(int j = 0; j < M; j++){
                grid[i][j] = Integer.parseInt(arr[j]);
            }
        }

        Queue<Node> q = new LinkedList<>();
        int[][][] dp = new int[N][M][2];
        dp[0][0][0] = 1;

        q.add(new Node(0,0,0,1));

        int answer = -1;
        while(!q.isEmpty()){
            Node curr = q.poll();
            int x = curr.x;
            int y = curr.y;
            int cnt = curr.cnt;
            int used = curr.used;
            if(x == N -1 && y == M - 1) {
                answer = cnt;
                break;
            };

            // 아직 벽을 안부섰을때
            if(used == 0){
                for(int i = 0; i < 4; i++){
                    int nx = x + dxs[i];
                    int ny = y + dys[i];
                    if(!inRange(nx,ny)) continue;
                    // 다음 칸이 벽이면
                    if(grid[nx][ny] == 1){
                        if(dp[nx][ny][1] == 0){
                            dp[nx][ny][1] = cnt + 1;
                            q.add(new Node(nx,ny,1, cnt + 1));
                        }
                    }
                    else{
                        if(dp[nx][ny][used] == 0){
                            dp[nx][ny][0] = cnt + 1;
                            q.add(new Node(nx,ny,0, cnt + 1));
                        }
                    }
                }
            }
            // 이미 벽을 부섰으면
            else{
                for(int i = 0; i < 4; i++){
                    int nx = x + dxs[i];
                    int ny = y + dys[i];
                    if(!inRange(nx,ny) || grid[nx][ny] == 1) continue;
                    if(dp[nx][ny][1] == 0){
                        dp[nx][ny][1] = cnt + 1;
                        q.add(new Node(nx,ny,1,cnt + 1));
                    }
                }
            }
        }

        System.out.println(answer);
    }

    static boolean inRange(int nx, int ny){
        return nx >= 0 && nx < N && ny >= 0 && ny < M;
    }
}
```

## 처음 접근

## 핵심 아이디어

`Node`에 위치 `(x, y)`, 벽 사용 여부 `used`, 현재 경로 길이 `cnt`를 저장한다.
같은 위치라도 벽을 부순 상태와 아직 부수지 않은 상태에서 이후 가능한 이동이 다르므로 `dp[x][y][used]`로 방문을 구분한다.
`dp`의 0은 미방문을 의미하고 방문 시 경로 길이를 저장한다.
벽을 사용하지 않았다면 다음 칸이 벽일 때 사용 상태를 1로 바꿔 이동할 수 있다. 이미 사용했다면 빈칸으로만 이동한다.
모든 이동 비용이 같으므로 BFS에서 도착점을 처음 꺼냈을 때의 길이가 최단 거리다. 시작 길이를 1로 두어 시작 칸도 센다.

## 복잡도

- 시간 복잡도: O(NM). 칸마다 벽 사용 여부에 따른 두 상태를 각각 최대 한 번 방문하고 네 방향을 확인한다.
- 공간 복잡도: O(NM). 지도, 두 상태의 방문·거리 배열, BFS 큐를 사용한다.

## 반례와 경계 조건

- 최소 입력: 1×1의 빈칸은 결과가 1이다. 기록 시 검증했다.
- 최대 입력: 1000×1000의 모든 칸이 빈칸이면 결과는 1999다. 기록 시 검증했다.
- 한 행 `010`과 한 열 `0, 1, 0`은 한 벽을 부수어 결과가 3이다. 모두 검증했다.
- 한 행 `0110`은 두 벽을 지나야 하므로 결과가 -1이다. 검증했다.
- 벽을 부수지 않는 경로도 허용된다.
- 같은 위치에 도달해도 벽 사용 여부가 다르면 별도로 방문할 수 있어야 한다.
- 시작점과 도착점을 모두 경로 길이에 포함한다.
