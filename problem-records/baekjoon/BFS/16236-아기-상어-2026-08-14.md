## 문제 요약

아기 상어가 이동 가능한 칸을 따라 가장 가까운 먹이를 반복해서 선택한다. 거리가 같으면 위쪽, 다시 같으면 왼쪽 물고기를 먼저 먹으며, 성장 규칙을 적용해 더 먹을 수 없을 때까지 걸린 시간을 구한다.

## 입출력

- 입력: 공간 크기 N과 물고기 크기 및 상어 위치(9)가 담긴 N×N 공간
- 출력: 아기 상어가 물고기를 잡아먹으며 이동한 총 시간

## 최종 Solution 코드

```java
import java.util.*;
public class Solution {
    int N;
    int[] dxs = {1,0,-1,0};
    int[] dys = {0,1,0,-1};
    int size = 2;
    class Node{
        int x;
        int y;
        int sx;
        int sy;
        int dis;
        public Node(int x, int y,int sx, int sy, int dis){
            this.x = x;
            this.y = y;
            this.sx = sx;
            this.sy = sy;
            this.dis = dis;
        }
    }
    // 먹을 수 있는 물고기 후보군 (거리 -> x -> y 오름차순)
    PriorityQueue<Node> pq = new PriorityQueue<>((a,b) -> {
        if(a.dis != b.dis) return Integer.compare(a.dis, b.dis);
        if(a.x != b.x) return Integer.compare(a.x, b.x);
        return Integer.compare(a.y, b.y);
    });
    int answer = 0;
    public int solution(int n, int[][] space) {

        // 기본적인 상어 움직임은 상하좌우 1
        // 먹을 수 잇는 물고기 모음 pq를 이용해서 Node(x,y,dis)로 dis - x-y 각각 오름차순으로 조건
        // 무한루프를 하지만 pq가 빌때까지(먹을 수 있는 물고기가 없을때까지)
        // 상어의 위치마다 먹을 수 있는 물고기의 거리가 달라지므로 각 위치에서 계속 pq최산화, 상어 크기도 최신화
        // 상어와 물고기의 거리는 맨하튼 거리가 아닌 실제 이동할 수 있는거리(bfs로 구한다)
        N = n;

        int startX = 0;
        int startY = 0;
        // 최초 물고기 위치 확인 및 먹을 수 있는 생선 등록
        for(int i = 0; i < N; i++){
            for(int j = 0; j < N; j++){
                if(space[i][j] == 9){
                    startX = i;
                    startY = j;
                    getFish(startX, startY,space);
                }
            }
        }

        int cnt = 0;
        // 본격적 진행
        while(!pq.isEmpty()){
            // 먹을 물고기
            Node curr = pq.poll();

            // 이미 먹은 위치/ 시작점이 다른 지점은 스킵
            if(space[curr.x][curr.y] == 0 || !(curr.sx == startX && curr.sy == startY)) continue;
            cnt += 1;
            space[startX][startY] = 0;
            startY = curr.y;
            startX = curr.x;
            answer += curr.dis;
            System.out.println(curr.dis);
            if(cnt == size){
                size += 1;
                cnt = 0;
            }
            // 현재 위치에서 다시 먹을 물고기 후보 먹기
            getFish(startX, startY,space);

        }

        return answer;
    }
    private void getFish(int x, int y, int[][] space){
        Queue<int[]> q = new LinkedList<>();
        boolean[][] visited = new boolean[N][N];
        int[][] disInfo = new int[N][N];
        visited[x][y] = true;
        q.add(new int[]{x,y});

        while(!q.isEmpty()){
            int[] curr = q.poll();
            int currX = curr[0];
            int currY = curr[1];
            int dis = disInfo[currX][currY];
            if(space[currX][currY] != 0 && space[currX][currY] < size && dis > 0){
                pq.add(new Node(currX, currY, x, y, dis));
            }

            for(int i = 0; i < 4; i++){
                int nx = currX + dxs[i];
                int ny = currY + dys[i];
                if(inRange(nx,ny) && !visited[nx][ny] && space[nx][ny] <= size){
                    q.add(new int[]{nx,ny});
                    disInfo[nx][ny] = dis + 1;
                    visited[nx][ny] = true;
                }
            }
        }
    }

    private boolean inRange(int nx, int ny){
        return nx >= 0 && nx < N && ny >= 0 && ny < N;
    }
}
```

## 핵심 아이디어

매번 현재 위치에서 BFS를 수행해 실제 최단거리를 계산하고, 후보를 거리·위쪽·왼쪽 순으로 정렬해 하나씩 먹는다. 먹은 횟수가 현재 크기와 같아지면 상어를 성장시킨다.

## 피드백 및 개선 코드

현재 풀이는 `PriorityQueue<Node>`를 전역으로 두기 때문에 이전 상어 위치에서 만든 후보가 큐에 남는다. `sx`, `sy`를 비교해 오래된 후보를 건너뛰므로 정답은 구할 수 있지만, 사용하지 않을 `Node`를 저장하고 다시 꺼내는 작업이 발생한다.

한 번의 BFS가 담당할 일을 **현재 위치에서 다음에 먹을 물고기 한 마리 찾기**로 한정하면 전역 우선순위 큐가 필요 없다. `getFish()`가 거리, 행, 열 우선순위가 가장 높은 `Node` 하나를 반환하고, 먹을 수 있는 물고기가 없으면 `null`을 반환하도록 구성할 수 있다. 이 경우 `Node`의 `sx`, `sy`와 오래된 후보를 검사하는 조건도 제거할 수 있다.

```java
while(true){
    Node fish = getFish(startX, startY, space);
    if(fish == null) break;

    space[startX][startY] = 0;
    startX = fish.x;
    startY = fish.y;
    answer += fish.dis;
    cnt += 1;

    if(cnt == size){
        size += 1;
        cnt = 0;
    }
}
```

```java
private Node getFish(int x, int y, int[][] space){
    Queue<int[]> q = new LinkedList<>();
    boolean[][] visited = new boolean[N][N];
    int[][] disInfo = new int[N][N];
    Node best = null;

    visited[x][y] = true;
    q.add(new int[]{x, y});

    while(!q.isEmpty()){
        int[] curr = q.poll();
        int currX = curr[0];
        int currY = curr[1];
        int dis = disInfo[currX][currY];

        if(best != null && dis > best.dis) break;

        if(space[currX][currY] != 0
                && space[currX][currY] < size
                && dis > 0){
            if(best == null
                    || currX < best.x
                    || (currX == best.x && currY < best.y)){
                best = new Node(currX, currY, dis);
            }
            continue;
        }

        for(int dir = 0; dir < 4; dir++){
            int nx = currX + dxs[dir];
            int ny = currY + dys[dir];

            if(inRange(nx, ny)
                    && !visited[nx][ny]
                    && space[nx][ny] <= size){
                visited[nx][ny] = true;
                disInfo[nx][ny] = dis + 1;
                q.add(new int[]{nx, ny});
            }
        }
    }

    return best;
}
```

위 개선 코드에서는 `Node` 생성자도 현재 위치 정보가 필요 없으므로 다음처럼 단순화할 수 있다.

```java
public Node(int x, int y, int dis){
    this.x = x;
    this.y = y;
    this.dis = dis;
}
```
