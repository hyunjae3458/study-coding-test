## 문제 요약

R, G, B로 이루어진 그림에서 상하좌우로 연결된 같은 색 칸들을 하나의 구역으로 센다.
R과 G를 구분하는 경우와 같은 색으로 보는 경우의 구역 수를 각각 구한다.

## 입출력

- 입력: N (1 ≤ N ≤ 100), 이어서 N줄에 길이 N인 색 문자열이 공백 없이 주어진다.
- 출력: 적록색약이 아닌 사람이 보는 구역 수, 적록색약인 사람이 보는 구역 수를 공백으로 구분한다.

### 예제 입력

```text
5
RRRBB
GGBBB
BBBRR
BBRRR
RRRRR
```

### 예제 출력

```text
4 3
```

## 최종 Main 코드

사용자가 작성한 `src/Main.java` 전체를 원형 그대로 보존한다.

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;

public class Main {
    static int N;
    static int[] dxs= {1,0,-1,0};
    static int[] dys= {0,1,0,-1};
    public static void main(String[] args) throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        N = Integer.parseInt(bf.readLine());

        String[][] normalGrid = new String[N][N];
        String[][] notNormalGrid = new String[N][N];
        for(int i = 0; i < N; i++){

            String[] arr = bf.readLine().split("");
            for(int j = 0; j < arr.length; j++){
                normalGrid[i][j] = arr[j];
                if(arr[j].equals("G")){
                    notNormalGrid[i][j] = "R";
                }
                else {
                    notNormalGrid[i][j] = arr[j];
                }
            }
        }

        // 정상
        int normal = 0;
        boolean[][] visited = new boolean[N][N];
        for(int i = 0; i < N; i++){
            for(int j = 0; j < N; j++){
                if(!visited[i][j]){
                    bfs(i,j,normalGrid[i][j], normalGrid,visited);
                    normal += 1;
                }
            }
        }

        // 비정상
        int noNormal = 0;
        visited = new boolean[N][N];
        for(int i = 0; i < N; i++){
            for(int j = 0; j < N; j++){
                if(!visited[i][j]){
                    bfs(i,j,notNormalGrid[i][j], notNormalGrid,visited);
                    noNormal += 1;
                }
            }
        }

        System.out.println(normal + " " + noNormal);
    }

    static void bfs(int x, int y, String color, String[][] grid, boolean[][] visited){
        Queue<int[]> q = new LinkedList<>();
        q.add(new int[]{x,y});
        visited[x][y] = true;


        while (!q.isEmpty()){
            int[] curr = q.poll();
            int cx = curr[0];
            int cy = curr[1];

            for(int i = 0; i < 4; i++){
                int nx = cx + dxs[i];
                int ny = cy + dys[i];
                if(inRange(nx,ny) && !visited[nx][ny] && grid[nx][ny].equals(color)){
                    visited[nx][ny] = true;
                    q.add(new int[]{nx,ny});
                }
            }
        }
    }

    static boolean inRange(int nx, int ny){
        return nx >=0 && nx < N && ny >=0 && ny < N;
    }
}
```

## 처음 접근

처음 구상한 과정은 기록되지 않음. 확인된 최종 풀이에서는 원본 그림과 G를 R로 바꾼 그림을 따로 만들고 각각 BFS로 구역 수를 구한다.

## 처음 틀렸던 점

## 수정 과정

사용자 수정 이력은 기록되지 않음. 기록 및 제출 파일 생성 과정에서 코드를 수정하지 않았다.

## 핵심 아이디어

원본 색을 담은 `normalGrid`와 G를 R로 통일한 `notNormalGrid`를 준비한다.
각 그림을 순회하며 아직 방문하지 않은 칸에서 같은 색만 따라 BFS를 수행하고 구역 수를 1씩 증가시킨다.
두 번째 그림을 검사할 때 방문 배열을 새로 만든다. 큐에 넣는 즉시 방문 표시하여 중복 탐색을 방지한다.

## 복잡도

- 시간 복잡도: O(N²). 두 그림 각각에서 모든 칸과 네 방향을 상수 번 확인한다.
- 공간 복잡도: O(N²). 두 그림, 방문 배열, BFS 큐가 필요하다.

## 반례와 경계 조건

- 최소 입력: N=1에서 R, G, B 각각 결과는 `1 1`이다. 세 경우 모두 검증했다.
- 최대 입력: N=100에서 모든 칸이 R이면 `1 1`이다. 검증했다.
- R/G가 번갈아 있는 2×2 그림은 `4 1`이다. 검증했다.
- R/B가 번갈아 있는 2×2 그림은 `4 4`이다. 대각선은 연결로 취급하지 않는다. 검증했다.
- 두 번째 탐색에서는 방문 배열을 초기화하고, 출력 순서는 원본 그림의 결과가 먼저다.
