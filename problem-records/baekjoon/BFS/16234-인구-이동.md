## 문제 요약

N×N 나라에서 인접한 나라의 인구 차이가 L 이상 R 이하이면 하루 동안 국경을 연다. 연결된 연합의 인구를 평균의 정수 부분으로 맞추며, 더 이상 이동이 없을 때까지 걸린 일수를 구한다.

## 입출력

- 입력: N, L, R과 N×N 인구 배열. 1 ≤ N ≤ 50, 1 ≤ L ≤ R ≤ 100, 인구는 0~100이다. 이동 일수는 2,000 이하로 보장된다.
- 출력: 인구 이동이 발생한 일수.

### 예제 입력

```text
3 5 10
10 15 20
20 30 25
40 22 10```

### 예제 출력

```text
2```

## 최종 Main 코드

사용자가 작성한 `src/Main.java` 전체를 그대로 보존했다.

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;

public class Main {
    static int[] dxs = {1,0,-1,0};
    static int[] dys = {0,1,0,-1};
    static Map<Integer, Node> map;
    static int[][] dp;
    static int[][] grid;
    static int N;
    static int L;
    static int R;
    static class Node{
        int size;
        int sum;
        Node(int size, int sum){
            this.size = size;
            this.sum = sum;
        }
    }
    public static void main(String[] args) throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(bf.readLine());
        N = Integer.parseInt(st.nextToken());
        L = Integer.parseInt(st.nextToken());
        R = Integer.parseInt(st.nextToken());
        dp = new int[N][N];
        grid = new int[N][N];
        for(int i = 0; i < N; i++){
            st = new StringTokenizer(bf.readLine());
            for(int j = 0; j < N; j++){
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int answer = 0;
         while(true){
             map = new HashMap<>();
             dp = new int[N][N];
             int cnt = 1;
             for(int i = 0; i < N; i++){
                 for(int j = 0; j < N; j++){
                     if(dp[i][j] == 0){
                         bfs(i,j,cnt);
                         cnt += 1;
                     }

                 }
             }

             if(map.isEmpty()) break;
             for(int i = 0; i < N; i++){
                 for(int j = 0; j < N; j++){
                     if(map.containsKey(dp[i][j])){
                         grid[i][j] = map.get(dp[i][j]).sum / map.get(dp[i][j]).size;
                     }
                 }
             }
             answer += 1;

         }

        System.out.println(answer);
    }

    static void bfs(int x, int y, int cnt){
        Queue<int[]> q = new LinkedList<>();
        dp[x][y] = cnt;
        q.add(new int[]{x,y});

        while(!q.isEmpty()){
            int[] curr = q.poll();
            int currX = curr[0];
            int currY = curr[1];

            for(int i = 0; i < 4; i++){
                int nx = currX + dxs[i];
                int ny = currY + dys[i];
                if(inRange(nx,ny) && dp[nx][ny] == 0 && check(grid[currX][currY], grid[nx][ny])){
                    dp[nx][ny] = cnt;
                    q.add(new int[]{nx,ny});
                    if(!map.containsKey(cnt)){
                        map.put(cnt, new Node(1,grid[x][y]));
                    }
                    map.get(cnt).size += 1;
                    map.get(cnt).sum += grid[nx][ny];
                }
            }

        }
    }

    static boolean check(int c, int n){
        return Math.abs(c-n) >= L && Math.abs(c-n) <= R;
    }

    static boolean inRange(int nx, int ny){
        return nx >= 0 && nx < N && ny >= 0 && ny < N;
    }
}
```

## 처음 접근

BFS로 각 연합에 번호를 붙이고, `dp`에 소속 번호를 저장했다. `map`에는 이동이 발생하는 연합의 인구 합과 크기를 저장하고, 하루 탐색이 끝난 후 격자의 인구를 일괄 갱신했다.

## 처음 틀렸던 점

- 틀린 원인: 연합 구분에 사용하는 `cnt`를 안쪽 반복문에서 매번 1로 초기화해 서로 다른 연합을 같은 번호로 처리했다.
- 놓친 조건: 같은 날 서로 다른 연합은 별도의 번호와 집계가 필요하다.
- 당시 코드의 핵심 부분:

```java
             for(int i = 0; i < N; i++){
                 for(int j = 0; j < N; j++){
                     int cnt = 1;
                     if(dp[i][j] == 0){
                         bfs(i,j,cnt);
                     }
                     cnt += 1;
                 }
             }
```

첫 채점에서 공식 예제 4는 기대 2 / 실제 1, 공식 예제 5는 기대 3 / 실제 1이었다. 전체 113개 중 61개 통과, 52개 실패했다.

## 수정 과정

사용자가 `int cnt = 1;`을 하루의 이중 반복문 바깥으로 옮겼다. 재채점에서 356개를 모두 통과했다. 에이전트는 풀이 코드를 수정하지 않았다.

2026-11-12 문제 전환 전 최신 코드 확인: 사용자가 `cnt` 증가를 BFS 호출 조건 안으로 옮긴 버전도 356개 테스트와 제출 파일 핵심 13개 재검증을 모두 통과했다. 최종 코드와 제출 파일에 이 버전을 보존했다. 상태는 로컬 확장 채점 통과로 유지한다.

## 핵심 아이디어

`dp`로 방문 여부와 연합 번호를 함께 관리한다. BFS는 해당 날짜의 기존 인구를 기준으로 연결된 나라를 찾는다. 두 번째 나라가 합류할 때 시작 나라의 인구와 크기를 포함하여 `map`에 연합을 생성한다. 모든 탐색 후 각 연합의 인구 합을 나라 수로 나누어 갱신하므로 같은 날 다른 탐색에 인구 변경이 영향을 주지 않는다. 이동 가능한 연합이 하나도 없으면 `map`이 비어 반복을 종료한다.

## 복잡도

- 시간 복잡도: 이동 일수 D에 대해 O((D+1)N²). 해시맵 연산을 평균 O(1)로 가정하며, 종료 확인을 위한 마지막 하루 탐색도 포함한다.
- 공간 복잡도: O(N²). 격자, 방문 배열, 연합 정보와 BFS 큐를 사용한다.

## 반례와 경계 조건

- N=1 및 모든 나라의 인구가 같을 때 이동 일수는 0이다.
- 인구 차이가 L 또는 R과 같아도 국경을 연다. L=R도 허용된다.
- 인구가 0인 나라와 100인 나라를 포함한다.
- 같은 날 여러 개의 독립된 연합이 생길 수 있다.
- 연합 인구 평균의 소수점 이하는 버린다.
- 이동이 일어나지 않는 한 나라짜리 연합은 갱신할 필요가 없다.
- 매일 방문 배열과 연합 정보를 초기화하고 종료 확인일은 답에 더하지 않는다.
