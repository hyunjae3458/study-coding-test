## 문제 요약

N×N 공간에서 아기 상어가 물고기를 먹으며 이동하는 총 시간을 구한다.
상어는 처음 크기가 2이며, 자신보다 큰 물고기가 있는 칸으로 이동할 수 없다.
자신보다 작은 물고기만 먹을 수 있고, 가장 가까운 물고기부터 먹는다.
거리가 같으면 가장 위쪽, 그다음 가장 왼쪽 물고기를 선택한다.
현재 크기만큼 물고기를 먹으면 크기가 1 증가한다.

## 입출력

- 입력: 2 ≤ N ≤ 20인 공간 크기와 N×N 배열. 0은 빈칸, 1~6은 물고기 크기, 9는 아기 상어의 초기 위치다.
- 함수: `solution(int n, int[][] space)`. 원본 값과 순서를 그대로 전달한다. 배열 인덱스는 0-based다.
- 출력: 더 먹을 수 있는 물고기가 없을 때까지 이동한 총 시간.
- 아래는 현재 `input.txt`, `output.txt`의 공식 예제 1이다. 전체 6개는 `examples/baekjoon/16236/`에 보관한다.

### 예제 입력

```text
3
0 0 0
0 0 0
0 9 0
```

### 예제 출력

```text
0
```

## 최종 Solution 코드

```java
import java.util.*;
public class Solution {
    /**
     * @param n 공간의 크기 N (입력값 그대로)
     * @param space N×N 공간, 입력 행·열 순서와 값 그대로.
     *              0은 빈칸, 1~6은 물고기 크기, 9는 아기 상어의 위치.
     *              배열 인덱스는 0-based이며 space[0][0]은 첫 행 첫 열.
     * @return 아기 상어가 물고기를 잡아먹을 수 있는 총 시간
     */
    class Node{
        int x;
        int y;
        int dis;
        public Node(int x, int y, int dis){
            this.x = x;
            this.y= y;
            this.dis =dis;
        }
    }
    int[] dxs = {1,0,-1,0};
    int[] dys = {0,1,0,-1};
    int size = 2;
    int x;
    int y;
    public int solution(int n, int[][] space) {
        for(int i = 0; i < n; i++){
            for(int j = 0; j < n; j++){
                if(space[i][j] == 9){
                    x = i;
                    y = j;
                }
            }
        }
        int cnt = 0;
        int answer = 0;
        while(true){
            PriorityQueue<Node> pq = new PriorityQueue<>((a,b) -> {
                if(a.dis != b.dis) return a.dis - b.dis;
                else if(a.x != b.x) return a.x - b.x;
                else return a.y - b.y;
            });

            move(pq, space);

            if(pq.isEmpty()) break;
            Node next = pq.poll();
            space[x][y] = 0;
            x = next.x;
            y = next.y;
            answer += next.dis;
            space[x][y] = 9;
            cnt += 1;
            if(cnt == size) {
                cnt = 0;
                size += 1;
            }
        }
        return answer;
    }

    private void move(PriorityQueue<Node> pq, int[][] space){
        boolean[][] visited = new boolean[space.length][space.length];
        Queue<Node> q = new LinkedList<>();
        int best = Integer.MAX_VALUE;
        q.add(new Node(x,y,0));
        visited[x][y] = true;

        while(!q.isEmpty()){
            Node curr = q.poll();
            int currX = curr.x;
            int currY = curr.y;
            int dis = curr.dis;
            int fishSize = space[currX][currY];
            if(best < dis) break;
            if(fishSize != 0 && fishSize != 9 && fishSize < size){
                pq.add(new Node(currX, currY, dis));
                best = dis;
            }

            for(int i = 0; i < 4; i++){
                int nx = currX + dxs[i];
                int ny = currY + dys[i];
                if(inRange(nx,ny,space.length) && !visited[nx][ny] && space[nx][ny] <= size){

                    q.add(new Node(nx,ny,dis + 1));
                    visited[nx][ny] = true;
                }
            }
        }
    }

    private boolean inRange(int nx, int ny, int n){
        return nx >= 0 && nx < n && ny >= 0 && ny < n;
    }
}
```

## 처음 접근

이번 재풀이에서는 현재 상어 위치에서 BFS를 수행해 먹을 수 있는 물고기를 찾고,
거리·행·열 순으로 정렬한 우선순위 큐에서 다음 먹이를 선택했다.
물고기를 먹을 때마다 우선순위 큐를 새로 생성하고, 상어 위치와 성장 횟수를 갱신했다.
최적화 전에는 도달 가능한 영역 전체를 탐색했다.

## 핵심 아이디어

- BFS로 장애물과 이동 조건을 반영한 실제 최단거리를 구한다.
- 첫 먹이를 찾은 거리와 같은 거리의 후보를 끝까지 수집하고, 더 먼 거리는 탐색을 종료한다.
- 우선순위 큐로 거리 → 행 → 열 순서를 적용한다.
- 이전 상어 위치는 0, 새 위치는 9로 갱신하고 이동 거리를 누적한다.
- 먹은 횟수가 현재 크기와 같아지면 크기를 늘리고 횟수를 0으로 초기화한다.

## 복잡도

F는 먹는 물고기 수이며 F ≤ N²−1이다.

- 시간 복잡도: O((F + 1) × N² log N)의 상한. 한 번의 BFS는 O(N²)이며 후보 우선순위 큐 연산을 포함한다. 거리 제한으로 실제 탐색을 줄이지만 최악 상한은 유지된다.
- 공간 복잡도: O(N²). 방문 배열, BFS 큐, 먹이 후보 큐를 포함한다.

## 반례와 경계 조건

- 최소 입력: N=2에서 먹을 물고기가 없으면 0을 반환한다.
- 최대 입력: N=20이며 물고기를 먹을 때마다 방문 배열과 후보를 새로 구성한다.
- 같은 크기의 물고기는 통과 가능하지만 먹을 수 없다.
- 더 큰 물고기는 통과할 수 없으므로 단순 좌표 거리로 먹이를 선택하면 안 된다.
- 같은 거리의 후보가 여러 개면 위쪽·왼쪽 우선순위를 모두 적용해야 한다.
- 첫 먹이를 찾자마자 종료하지 않고 같은 거리의 다른 후보까지 확인한다.
- 성장 직후에는 이동 가능 영역과 먹을 수 있는 물고기가 달라질 수 있다.
- 도달 가능한 먹이가 없으면 종료한다.
