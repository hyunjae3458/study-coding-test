## 문제 요약

양방향 가중치 그래프에서 1번부터 N번까지 이동하면서 지정된 두 정점 v1, v2를 모두 방문하는 최소 거리를 구한다. 정점과 간선은 재방문할 수 있다.

## 입출력

- 입력: N(2~800), E(0~200,000), 이어서 E개의 양방향 간선 a, b, c(가중치 1~1,000), 마지막으로 v1, v2가 주어진다. 정점 번호는 1-based다.
- v1과 v2는 서로 다르고 v1 ≠ N, v2 ≠ 1이다. 두 정점 사이 간선은 최대 하나다.
- 출력: 조건을 만족하는 최소 거리. 경로가 없으면 -1.

### 예제 입력

```text
4 6
1 2 3
2 3 3
3 4 1
1 3 5
2 4 5
1 4 4
2 3
```

### 예제 출력

```text
7
```

## 최종 Main 코드

사용자가 작성하여 온라인 정답을 확인한 코드 전체를 원형 그대로 보존한다.

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.sql.Array;
import java.util.*;

public class Main {
    static class Node{
        int node;
        int cost;
        Node(int node, int cost){
            this.node = node;
            this.cost = cost;
        }
    }
    static int N;
    static int E;
    static boolean possilbe = true;
    static List<Node>[] graph;
    public static void main(String[] args) throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(bf.readLine());

        N = Integer.parseInt(st.nextToken());
        E = Integer.parseInt(st.nextToken());
        graph = new ArrayList[N+1];
        for(int i = 0; i < N + 1; i++){
            graph[i] = new ArrayList<>();
        }

        // 그래프 생성
        for(int i = 0; i < E; i++){
            st = new StringTokenizer(bf.readLine());
            int start = Integer.parseInt(st.nextToken());
            int end = Integer.parseInt(st.nextToken());
            int cost = Integer.parseInt(st.nextToken());
            graph[start].add(new Node(end, cost));
            graph[end].add(new Node(start, cost));
        }
        st = new StringTokenizer(bf.readLine());
        int v1 = Integer.parseInt(st.nextToken());
        int v2 = Integer.parseInt(st.nextToken());

        // 중간지점끼리 가장 가까운 길이 구하기
        int vDist = dijkstra(v1, v2);
        // 출발지에서 종착지까지 출발지 - 중간지점 - 중간지점 - 도착지 순서에 따른 다른 값구하기
        int dist1 = dijkstra(1, v1) + vDist + dijkstra(v2, N);
        int dist2 = dijkstra(1, v2) + vDist + dijkstra(v1, N);

        if(!possilbe) System.out.println(-1);
        else System.out.println(Math.min(dist1, dist2));

    }

    static int dijkstra(int start, int end){
        PriorityQueue<Node> pq = new PriorityQueue<>((a,b) -> Integer.compare(a.cost, b.cost));
        int[] dp = new int[N + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);

        dp[start] = 0;
        pq.add(new Node(start, 0));

        while(!pq.isEmpty()){
            Node curr = pq.poll();
            int node = curr.node;
            int cost = curr.cost;
            if(dp[node] < cost) continue;

            for(int i = 0; i < graph[node].size(); i++){
                Node nextNode = graph[node].get(i);
                int next = nextNode.node;
                int nextCost = nextNode.cost;
                if(dp[next] > cost + nextCost){
                    dp[next] = cost + nextCost;
                    pq.add(new Node(next, dp[next]));
                }
            }
        }
        if(dp[end] == Integer.MAX_VALUE) possilbe = false;
        return dp[end];
    }
}
```

## 처음 접근

목적지까지의 거리 하나를 반환하는 `dijkstra(start, end)`를 사용했다. v1과 v2 사이 거리를 한 번 계산하고, 두 방문 순서의 나머지 구간을 네 번 계산해 총 5번 호출했다.

## 처음 틀렸던 점

기록되지 않음. 확인된 오답 코드나 오답 이력은 없다.

## 수정 과정

정답 코드는 수정하지 않았다. 사용자가 정답 확인 후 제안한 개선은 아래 별도 항목에 기록했다. 실제 사용자 풀이와 제출 파일에는 적용하지 않았다.

## 핵심 아이디어

반드시 방문해야 하는 정점의 순서를 `1 → v1 → v2 → N`, `1 → v2 → v1 → N`으로 나누고 각 구간의 최단 거리 합 중 작은 값을 선택한다. 모든 가중치가 양수이므로 다익스트라를 사용한다. 양방향 그래프이므로 v1과 v2 사이 거리는 양쪽 방향이 같다.

현재 함수도 내부적으로 시작점에서 모든 정점까지의 거리를 계산하지만, 반환할 때 목적지 하나의 거리만 꺼낸다. 필요한 정점들이 서로 연결되지 않으면 유효한 전체 경로도 존재하지 않는다.

## 개선안: 거리 배열 반환으로 3번만 실행

사용자 제안: 목적지 매개변수를 제거하고 `dijkstra(int start)`가 모든 정점까지의 최단 거리 배열을 반환하도록 한다. 시작점 1, v1, v2에서 각각 한 번씩 실행하고, 경로를 조합할 때 배열에서 필요한 도착점의 값을 조회한다.

기존 `Node`, `graph`, `N`을 그대로 사용하는 메서드 교체 예시다.

```java
static int[] dijkstra(int start){
    PriorityQueue<Node> pq = new PriorityQueue<>((a,b) -> Integer.compare(a.cost, b.cost));
    int[] dp = new int[N + 1];
    Arrays.fill(dp, Integer.MAX_VALUE);

    dp[start] = 0;
    pq.add(new Node(start, 0));

    while(!pq.isEmpty()){
        Node curr = pq.poll();
        int node = curr.node;
        int cost = curr.cost;
        if(dp[node] < cost) continue;

        for(int i = 0; i < graph[node].size(); i++){
            Node nextNode = graph[node].get(i);
            int next = nextNode.node;
            int nextCost = nextNode.cost;
            if(dp[next] > cost + nextCost){
                dp[next] = cost + nextCost;
                pq.add(new Node(next, dp[next]));
            }
        }
    }
    return dp;
}
```

기존 5회 호출과 출력 부분은 다음처럼 바꾼다. 전역 `possilbe`는 개선안에서는 필요하지 않다.

```java
int[] fromStart = dijkstra(1);
int[] fromV1 = dijkstra(v1);
int[] fromV2 = dijkstra(v2);

long dist1 = (long) fromStart[v1] + fromV1[v2] + fromV2[N];
long dist2 = (long) fromStart[v2] + fromV2[v1] + fromV1[N];
long answer = Math.min(dist1, dist2);
System.out.println(answer >= Integer.MAX_VALUE ? -1 : answer);
```

도달 불가능한 거리는 `Integer.MAX_VALUE`로 유지한다. 합산은 첫 항부터 `long`으로 변환해 오버플로를 방지한다. 이 문제에서 유효한 세 구간 합은 최대 `3 × (N - 1) × 1,000`이므로 `Integer.MAX_VALUE`보다 작다.

## 복잡도

- 시간 복잡도: 1회당 O((N + E) log N), 기존 5회에서 개선안 3회로 감소한다. 점근적 복잡도는 같지만 반복 탐색 비용이 줄어든다. 정확한 초기화 비용까지 포함하면 O(N + E log(E + 1))로도 표현할 수 있다.
- 공간 복잡도: O(N + E). 개선안은 거리 배열 3개를 보관하지만 같은 점근적 공간 복잡도다. 우선순위 큐에는 갱신 후보가 중복 저장될 수 있다.

## 반례와 경계 조건

- 최소 입력: N=2, E=0, v1=1, v2=2이면 -1.
- N=2에서 가중치 1,000인 간선 하나면 결과는 1,000.
- 최대 범위: N=800, E=200,000, 가중치 최대 1,000. 기록 시 최대 크기 성능 시험은 수행하지 않았다.
- v1=1 또는 v2=N일 수 있어 길이가 0인 구간도 허용한다.
- 두 방문 순서의 거리가 다를 수 있으므로 모두 비교한다.
- 필수 정점이나 도착점이 연결되지 않은 경우 -1을 출력한다.
- 이미 방문한 정점과 간선의 재사용이 허용된다.
- 개선안에서 무한대 값을 더할 때 int 오버플로에 주의한다.
