## 문제 요약

8개의 톱니를 가진 톱니바퀴 4개가 일렬로 놓여 있다. 회전 명령을 순서대로 수행하며, 맞닿은 극이 다른 인접 톱니바퀴는 반대 방향으로 회전한다. 모든 명령을 수행한 뒤 각 톱니바퀴의 12시 방향 극에 따른 점수의 합을 구한다.

## 입출력

- 입력: 톱니바퀴 1~4번의 초기 상태를 각각 8자리로 받는다. 각 줄은 12시부터 시계 방향 순서이며 0은 N극, 1은 S극이다. 다음으로 회전 횟수 K(1~100), 이어서 K개의 {번호, 방향} 명령을 받는다.
- 함수 파라미터: gears는 입력 순서대로 4×8 배열, k는 회전 횟수, rotations는 K×2 배열이다. 명령 번호는 1~4 그대로이며 방향 1은 시계, -1은 반시계다.
- 출력: 12시 방향이 S극인 톱니바퀴에 대해 1~4번에 각각 1, 2, 4, 8점을 더한 값이다.
- 현재 기본 입출력은 공식 예제 3이다. 공식 예제 1~4는 examples/baekjoon/14891/에 보관되어 있다.

### 예제 입력

```text
10001011
10000011
01011011
00111101
5
1 1
2 1
3 1
4 1
1 -1
```

### 예제 출력

```text
6
```

## 최종 Solution 코드

```java
import java.util.*;
public class Solution {
    /**
     * @param gears 4×8 톱니바퀴 상태. 행 0~3은 입력 순서대로 1~4번 톱니바퀴.
     *              각 행은 12시 방향부터 시계 방향 순서이며, 0은 N극, 1은 S극.
     * @param k 회전 횟수 K (입력값 그대로)
     * @param rotations K×2 회전 명령. 각 행은 {톱니바퀴 번호, 방향}.
     *                  번호는 1-based(1~4), 방향은 1(시계), -1(반시계) 그대로 전달.
     * @return 모든 회전 후 네 톱니바퀴의 점수 합
     */
    public int solution(int[][] gears, int k, int[][] rotations) {
        for(int i = 0; i < k; i++){
            int[] status = new int[4];
            int weal = rotations[i][0];
            int dir = rotations[i][1];
            check(weal, dir, status, gears);
            for(int s = 0; s < 4; s++){
                move(status[s], s, gears);
            }
        }

        int answer = 0;
        for(int i = 0; i < 4; i++){

            if(gears[i][0] == 1){
                answer += (int)Math.pow(2, i);
            }
        }
        return answer;
    }

    private void check(int weal, int dir, int[] status , int[][] gears){
        status[weal-1] = dir;
        for(int i = weal - 1; i > 0; i--){
            // 왼쪽 검사
            if(status[i] != 0 && gears[i][6] != gears[i -1][2]){
                status[i-1] = -status[i];
            } else{
                status[i-1] = 0;
            }
        }
        // 오른쪽 검사
        for(int i = weal - 1; i < 3; i++){
            if(status[i] != 0 && gears[i][2] != gears[i+1][6]){
                status[i+1] = -status[i];;
            } else{
                status[i + 1] = 0;
            }
        }

    }

    private void move(int status, int weal, int[][] gears){
        if(status == -1){
            int temp1 = gears[weal][7];
            int temp2 = 0;
            for(int i = 7; i > 0; i--){
                temp2 = gears[weal][i-1];
                gears[weal][i - 1] = temp1;
                temp1 = temp2;
            }
            gears[weal][7] = temp1;
        }
        if(status == 1){
            int temp1 = gears[weal][0];
            int temp2 = 0;
            for(int i = 0; i < 7; i++){
                temp2 = gears[weal][i+1];
                gears[weal][i+1] = temp1;
                temp1 = temp2;
            }
            gears[weal][0] = temp1;
        }
    }
}
```

## 핵심 아이디어

- 한 명령의 회전 방향은 톱니바퀴를 실제로 움직이기 전 상태를 기준으로 결정한다.
- 왼쪽 이웃은 현재 톱니의 6번 위치와 이웃의 2번 위치, 오른쪽 이웃은 현재의 2번 위치와 이웃의 6번 위치를 비교한다.
- 앞선 톱니바퀴가 회전하고 맞닿은 극이 다를 때만 반대 방향을 전파한다. 회전하지 않는 톱니바퀴를 만나면 그 너머에도 회전이 전달되지 않는다.
- 네 톱니바퀴의 회전 방향 결정 후 배열을 한 칸씩 이동하고, 최종 12시 방향의 극으로 점수를 계산한다.

## 복잡도

- 시간 복잡도: O(K). 톱니바퀴 수 4와 톱니 수 8이 고정되어 각 명령 처리는 상수 시간이다.
- 공간 복잡도: 풀이의 추가 공간 O(1). 입력 명령 배열을 포함하면 O(K)이며 톱니 상태는 원본 배열에서 갱신한다.

## 반례와 경계 조건

다음은 복습 시 확인할 조건이며, 별도 확장 테스트를 수행했다는 의미는 아니다.

- 최소 입력: K=1, 양 끝 톱니바퀴를 회전시키는 경우.
- 최대 입력: K=100, 동일 톱니바퀴를 반복 회전하거나 방향을 번갈아 바꾸는 경우.
- 모든 극이 N극이면 점수는 0, 모든 극이 S극이면 점수는 15다.
- 인접한 극이 같아서 회전 전파가 중간에 끊기는 경우.
- 중앙 톱니바퀴에서 좌우 양쪽으로 회전이 전달되는 경우.
- 시계·반시계 이동에서 양 끝 원소가 올바르게 순환하는지 확인한다.
- 회전 중 바뀐 극을 같은 명령의 전파 판단에 사용하지 않는다.
- 명령의 1-based 번호와 배열의 0-based 인덱스를 구분한다.
