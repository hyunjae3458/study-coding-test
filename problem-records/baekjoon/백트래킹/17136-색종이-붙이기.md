## 문제 요약

10×10 격자의 모든 1을 정사각형 색종이로 덮는다. 크기 1×1부터 5×5까지 각각 5장씩 사용할 수 있다. 색종이는 겹치거나 격자를 벗어나거나 0을 덮을 수 없다. 필요한 최소 장수를 구한다.

## 입출력

- 입력: 10줄에 각 10개씩 0 또는 1이 주어진다.
- 출력: 필요한 최소 장수. 불가능하면 -1.

## 1. 처음 접근 — 큰 색종이부터 붙이기

크기 5부터 1까지 순서대로 격자를 훑으며 붙일 수 있는 색종이를 즉시 붙였다. `check`로 해당 영역을 확인하고, `paint`로 0으로 덮은 뒤 남은 수량을 차감했다. 한 번 붙인 선택은 되돌리지 않았다.

### 당시 코드의 핵심 부분

```java
        // 5크기부터 순서대로 소비
        for(int i = 5; i > 0; i--){
            work(i);
        }
```

```java
    // 각 종류의 색종이 검증 작업
    static void work(int size){
        for(int i = 0; i <= 10 - size; i++){
            for(int j = 0; j <= 10 - size; j++){
                if(grid[i][j] == 0) continue;
                if(check(size, i,j) && map.get(size) > 0){
                    paint(size, i, j);
                    map.put(size, map.get(size) - 1);
                    answer += 1;
                }
            }
        }
    }
```

### 이 접근의 한계와 전환 계기

공식 예제 8개는 모두 통과했지만, 6×6 영역에서 기댓값 4와 달리 -1을 출력했다. 5×5를 먼저 붙이면 남은 영역을 덮을 1×1 색종이가 부족해진다. 반면 3×3 네 장을 사용하면 모두 덮을 수 있다.

즉, 큰 색종이를 먼저 확정하는 선택이 항상 최적의 배치나 가능한 배치를 보장하지 않는다. 사용자는 이 반례를 보고 각 좌표에서 크기를 바꿔 시도하는 백트래킹이 필요하다고 판단했다.

## 2. 최종 접근 — 백트래킹

사용자가 큰 색종이를 먼저 확정하는 방식의 한계를 파악하고, 좌표별로 가능한 크기를 시도하는 백트래킹으로 전환했다. `work(size)` 대신 `backtracking(xy, used)`로 좌표와 사용량을 관리하고, 재귀 호출 후 격자와 남은 색종이 수량을 복구한다. `answer`에는 완성된 배치의 최소 사용량을 저장한다. 최종 코드로 614개 테스트를 통과했다.

### 최종 Main 코드

사용자가 작성한 src/Main.java 전체를 원형 그대로 보존한다.

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;

public class Main {
    static int[][] grid = new int[10][10];
    static Map<Integer, Integer> map = new HashMap<>();
    static int answer = Integer.MAX_VALUE;
    public static void main(String[] args) throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));

        // 영역 초기화
        for(int i = 0; i < 10; i++){
            StringTokenizer st = new StringTokenizer(bf.readLine());
            for(int j = 0; j < 10; j++){
                grid[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        // 색종이 개수 초기화
        for(int i = 1; i <= 5; i++){
            map.put(i,5);
        }

        backtracking(0,0);
        if(answer == Integer.MAX_VALUE){
            System.out.println(-1);
        } else{
            System.out.println(answer);
        }
    }

    // 각 종류의 색종이 검증 작업
    static void backtracking(int xy, int used){
        if(xy > 99){
            answer = Math.min(answer, used);
            return;
        }
        int x = xy / 10;
        int y = xy % 10;

        if(answer <= used) return;
        if(grid[x][y] == 1){
            for(int i = 5; i > 0; i--){
                if(map.get(i) > 0 && check(i, x,y)){
                    paint(i, x,y,0);
                    map.put(i, map.get(i) - 1);
                    backtracking(xy + 1, used + 1);
                    paint(i,x,y,1);
                    map.put(i, map.get(i) + 1);
                }
            }
        } else{
            backtracking(xy + 1, used);
        }
    }

    // 색종이 검증 작업
    static boolean check(int size, int x, int y){
        if(x + size > 10 || y + size > 10) return false;
        for(int i = x; i < x + size; i++){
            for(int j = y; j < y + size; j++){
                if(grid[i][j] == 0) return false;
            }
        }

        return true;
    }

    // 색종이 입히기 작업
    static void paint(int size, int x, int y, int action){
        for(int i = x; i < x + size; i++){
            for(int j = y; j < y + size; j++){
                grid[i][j] = action;
            }
        }
    }
}
```

## 핵심 아이디어

좌표를 xy=0~99로 순회한다. 현재 칸이 0이면 다음 칸으로 넘어간다. 1이면 그 칸을 왼쪽 위 꼭짓점으로 덮을 수 있는 모든 크기를 시도한다. 앞선 칸은 이미 처리했으므로 이 순서로 빠짐없이 배치를 탐색할 수 있다. 색종이를 붙이면 영역을 0으로 바꾸고 수량을 줄인다. 재귀 호출 후 영역과 수량을 원상복구한다. 현재 사용량이 이미 찾은 최소 장수 이상이면 탐색을 중단한다.

## 복잡도

- 시간 복잡도: 백트래킹으로 지수적이다. 색종이 선택 분기는 최대 5개, 실제 붙이는 깊이는 총 보유량 25장 이하이다. 0인 칸 순회와 최대 25칸 검사·복구를 포함한 느슨한 상한은 O((100 + 5²) × 5²⁵)이다. 실제로는 격자 크기, 수량 제한, 유효 배치 검사와 가지치기로 탐색이 크게 감소한다.
- 공간 복잡도: 격자 O(100), 재귀 스택 O(100), 수량 저장 O(5). 고정 크기 문제에서는 상수 공간이다.

## 반례와 경계 조건

- 전부 0이면 0장, 전부 1이면 4장.
- 오른쪽 아래 한 칸만 1이면 1장.
- 6×6 영역은 4장으로 덮을 수 있다.
- 경계에 정확히 맞닿는 배치는 허용한다.
- 고립된 1이 6개 이상이고 큰 색종이를 붙일 수 없으면 불가능하다.
- 각 크기는 5장까지만 사용한다.
- 재귀 복귀 시 격자와 수량을 모두 복구한다.
