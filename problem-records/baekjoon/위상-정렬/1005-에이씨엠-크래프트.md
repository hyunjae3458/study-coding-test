## 문제 요약

건물별 건설 시간과 선행 건설 조건이 주어진다. 선행 건물을 모두 완성해야 다음 건물을 시작할 수 있고, 가능한 건물은 동시에 지을 수 있다. 목표 건물을 완성하는 최소 시간을 구한다.

## 입출력

- 입력: 테스트 케이스 수 T. 각 사례에 N, K, N개의 건설 시간, K개의 선행 관계 X Y, 목표 건물 W가 주어진다. 건물 번호는 1-based다.
- 제한: 2 ≤ N ≤ 1,000, 1 ≤ K ≤ 100,000, 건설 시간 0~100,000. 모든 건물이 건설 가능하도록 주어진다.
- 출력: 각 사례마다 W를 완성하는 최소 시간.

## 최종 Main 코드

사용자가 작성한 `src/Main.java` 전체를 원형 그대로 보존한다.

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.util.*;

public class Main {
    static class Node{
        int start;
        int end;
        Node(int start, int end){
            this.start = start;
            this.end = end;
        }
    }
    public static void main(String[] args) throws IOException {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(bf.readLine());
        for(int t = 0; t < T; t++){
            StringTokenizer st = new StringTokenizer(bf.readLine());
            int N = Integer.parseInt(st.nextToken());
            int K = Integer.parseInt(st.nextToken());
            // 건물짓는 시간
            int[] times = new int[N + 1];

            st = new StringTokenizer(bf.readLine());
            for(int i = 0; i < N; i++){
                times[i + 1] = Integer.parseInt(st.nextToken());
            }

            List<Integer>[] graph = new ArrayList[N + 1];
            for(int i = 0; i < N + 1; i++){
                graph[i] = new ArrayList<>();
            }
            int[] indegree = new int[N + 1];
            for(int i = 0; i < K; i++){
                st = new StringTokenizer(bf.readLine());
                int start = Integer.parseInt(st.nextToken());
                int end = Integer.parseInt(st.nextToken());

                graph[start].add(end);
                indegree[end] += 1;
            }

            int W = Integer.parseInt(bf.readLine());

            Queue<Integer> q = new LinkedList<>();
            int[] dp = new int[N + 1];
            for(int i = 1; i < N + 1; i++){
                if (indegree[i] == 0) {
                    q.add(i);
                    dp[i] = times[i];
                }
            }

            while(!q.isEmpty()){
                int curr = q.poll();
                if(curr == W){
                    break;
                }
                for(int i = 0; i < graph[curr].size(); i++){
                    int next = graph[curr].get(i);
                    if(dp[next] < times[next] + dp[curr]){
                        dp[next] = times[next] + dp[curr];
                    }
                    indegree[next] -= 1;
                    if (indegree[next] == 0) {
                        q.add(next);
                    }
                }
            }
            System.out.println(dp[W]);
        }

    }
}
```

## 처음 접근

진입 차수로 선행 건설 완료 여부를 관리하고, 큐로 건설 가능한 건물을 처리했다. 각 건물의 완성 시간을 `dp`에 저장하고 다음 건물에 전파했다.

## 처음 틀렸던 점

기록되지 않음. 현재 대화에서 확인된 오답 코드나 실패 이력은 없다.

## 수정 과정

해당 없음. 첫 채점에서 확장 테스트를 통과했으며, 사용자 코드를 수정하지 않고 기록과 제출 파일을 생성했다.

## 핵심 아이디어

선행 건물이 없는 건물은 자신의 건설 시간이 곧 완성 시간이다. 위상 순서로 처리하면서 다음 건물의 완성 시간을 `max(dp[next], dp[curr] + times[next])`로 갱신한다. 모든 선행 건물이 끝나야 시작할 수 있으므로 가장 늦게 끝나는 선행 경로가 기준이 된다. 진입 차수가 0이 되면 완성 시간이 확정되어 큐에 넣을 수 있다. 목표 건물을 큐에서 꺼낸 순간 답이 확정되어 탐색을 종료해도 된다.

## 복잡도

- 시간 복잡도: 테스트 케이스당 O(N + K).
- 공간 복잡도: O(N + K).

## 반례와 경계 조건

- 건설 시간이 0인 건물과 모든 시간이 0인 경우.
- 목표 건물에 선행 조건이 없거나 다른 연결 요소에 있는 경우.
- 여러 선행 경로의 완성 시간이 서로 다른 경우.
- 건물 번호가 선행 순서와 일치하지 않고, 간선 입력 순서도 임의인 경우.
- 여러 테스트 케이스 사이에 그래프, 진입 차수, 거리 배열이 새로 생성되어야 한다.
- N=1,000의 최대 비용 사슬은 100,000,000이며 int 범위 안에 있다.
- 간선 수 K=100,000인 입력.
