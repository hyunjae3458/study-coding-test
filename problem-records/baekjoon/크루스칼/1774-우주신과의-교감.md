# 백준 1774 - 우주신과의 교감

## 문제 정보

- 플랫폼: 백준 온라인 저지
- 문제 번호: 1774
- 난이도: 골드 III (solved.ac, 2026-08-04 확인)
- 문제 링크: https://www.acmicpc.net/problem/1774
- 풀이 날짜: 2026-08-04
- 결과: 정답
- 검증: 로컬 확장 채점 전체 통과 및 백준 반례 찾기 사이트에서 반례 미발견

## 문제 요약

2차원 좌표에 있는 우주신들과 황선자를 모두 연결해야 한다. 이미 연결된 통로는
추가 비용 없이 사용할 수 있을 때, 새로 만들어야 하는 통로 길이 합의 최솟값을
구한다.

## 입출력

- 입력: 우주신 수 `N`, 기존 통로 수 `M`, `N`개의 좌표, `M`개의 기존 통로
- 출력: 새로 만들 통로 길이 합의 최솟값을 소수점 둘째 자리까지 출력
- 템플릿의 `connectedPaths`는 원본 입력과 동일한 1-based 번호를 사용한다.

## 최종 코드

```java
import java.util.*;

public class Solution {
    class Node {
        int start;
        int end;
        double cost;

        public Node(int start, int end, double cost) {
            this.start = start;
            this.end = end;
            this.cost = cost;
        }
    }

    int[] parents;
    int[] size;
    PriorityQueue<Node> pq =
            new PriorityQueue<>((a, b) -> Double.compare(a.cost, b.cost));

    public double solution(int[][] positions, int[][] connectedPaths) {
        int n = positions.length + 1;
        parents = new int[n];
        size = new int[n];

        for (int i = 0; i < positions.length - 1; i++) {
            for (int j = i + 1; j < positions.length; j++) {
                double cost = Math.hypot(
                        positions[i][0] - positions[j][0],
                        positions[i][1] - positions[j][1]);
                pq.add(new Node(i + 1, j + 1, cost));
            }
        }

        for (int i = 1; i < n; i++) {
            parents[i] = i;
            size[i] = 1;
        }

        for (int[] path : connectedPaths) {
            int start = path[0];
            int end = path[1];
            if (find(start) != find(end)) {
                union(start, end);
            }
        }

        double answer = 0.0;
        while (!pq.isEmpty()) {
            Node current = pq.poll();
            if (find(current.start) != find(current.end)) {
                union(current.start, current.end);
                answer += current.cost;
            }
        }

        return answer;
    }

    private int find(int current) {
        if (parents[current] == current) return current;
        return parents[current] = find(parents[current]);
    }

    private void union(int first, int second) {
        int firstRoot = find(first);
        int secondRoot = find(second);

        if (firstRoot == secondRoot) return;

        if (size[firstRoot] < size[secondRoot]) {
            int temporary = size[firstRoot];
            size[firstRoot] = size[secondRoot];
            size[secondRoot] = temporary;
        }

        parents[secondRoot] = firstRoot;
        size[firstRoot] += size[secondRoot];
    }
}
```

## 처음 접근

모든 좌표 쌍의 직선거리를 계산해 비용 오름차순 우선순위 큐에 넣었다. 기존 통로를
먼저 같은 집합으로 합친 다음, 서로 다른 집합을 연결하는 거리만 정답에 더했다.

## 처음 틀렸던 점

사용자 풀이의 오답은 기록되지 않았다. 처음 실행이 예상과 달랐던 원인은 템플릿의
`Main`이 입력 통로 `1 4`를 임의로 `0 3`으로 변환해 전달한 것이었다. 이는 사용자
풀이 문제가 아니라 입력 어댑터 문제였으며, 원본 번호를 그대로 전달하도록 수정했다.

## 수정 과정

- `Main`에서 기존 통로 번호에 적용하던 `-1` 변환을 제거했다.
- 입력 `1 4`가 `connectedPaths`에도 `{1, 4}`로 전달되도록 변경했다.
- 사용자 풀이 코드는 변경하지 않고 확장 채점을 진행했다.

## 핵심 아이디어

- 두 좌표 사이의 길이는 `Math.hypot(dx, dy)`로 계산한다.
- 이미 연결된 통로의 양 끝점을 먼저 같은 집합으로 합친다.
- 거리 비용이 작은 좌표 쌍부터 서로 다른 집합만 연결한다.
- 새로 선택한 통로의 길이만 `double`로 누적한다.
- 출력 시 소수점 둘째 자리까지 포맷한다.

## 복잡도

- 좌표 쌍 생성: `O(N²)`
- 거리 후보 처리: `O(N² log N)`
- 공간 복잡도: `O(N²)`

## 반례와 경계 조건

- 우주신이 한 명뿐인 경우
- 모든 우주신이 기존 통로만으로 이미 연결된 경우
- 서로 같은 좌표에 여러 우주신이 있는 경우
- 직선거리가 정수가 아닌 경우와 소수점 반올림
- 기존 통로가 여러 개의 연결 집합을 만드는 경우
- 좌표가 최대 범위에 있는 경우
- 우주신 1,000명의 모든 좌표 쌍을 생성하는 경우

## 검증 결과
