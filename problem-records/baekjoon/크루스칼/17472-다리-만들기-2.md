# [백준] 17472 - 다리 만들기 2

## 문제 정보

- 플랫폼: 백준

- 결과: 로컬 확장 채점 통과

## 문제 요약

상하좌우로 이어진 땅을 각각 하나의 섬으로 구분하고, 길이가 2 이상인 가로 또는 세로 다리로 모든 섬을 연결할 때 다리 길이 합의 최솟값을 구한다. 모든 섬을 연결할 수 없다면 -1을 반환한다.

## 입출력

- 입력: 지도의 세로 크기 N, 가로 크기 M과 바다(0)·땅(1)으로 구성된 N×M 지도
- 출력: 모든 섬을 연결하는 다리 길이 합의 최솟값. 연결할 수 없다면 -1

## 최종 Solution 코드

```java
import java.util.*;
public class Solution {
    /**
     * @param n 세로 크기 (입력값 그대로)
     * @param m 가로 크기 (입력값 그대로)
     * @param map 0은 바다, 1은 땅인 N x M 지도 (입력 순서와 값 그대로)
     * @return 모든 섬을 연결하는 다리 길이의 최솟값, 연결할 수 없으면 -1
     */
    class Bridge{
        int start;
        int end;
        int cost;

        public Bridge(int start, int end, int cost){
            this.start = start;
            this.end = end;
            this.cost = cost;
        }
    }

    int[] parents;
    int[] size;
    List<Bridge> bridges = new ArrayList<>();
    int[] dxs = {1,0,-1,0};
    int[] dys = {0,1,0,-1};
    Queue<int[]> q = new LinkedList<>();
    int N;
    int M;
    public int solution(int n, int m, int[][] map) {
        N = n;
        M = m;
        // 그룹화
        // 그룹 id는 2부터시작(1이 땅이기 때문)
        int groupId = 2;
        for(int i = 0; i < n; i++){
            for(int j = 0; j < m; j++){
                if(map[i][j] == 1){
                    makeGroup(map, i, j, groupId);
                    groupId += 1;
                }
            }
        }

        // 다리 기록
        for(int i = 0; i < n; i++){
            for(int j = 0; j < m; j++){
                // 섬이라면
                if(map[i][j] != 0 && map[i][j] != 1){
                    // 섬의 한 지점에서 상하좌우를 봤을때 바다라면
                    for(int dir = 0; dir < 4; dir++){
                        int nextX = i + dxs[dir];
                        int nextY = j + dys[dir];
                        if(inRange(nextX, nextY) && map[nextX][nextY] == 0){
                            getBridge(map, nextX, nextY, dir, map[i][j]);
                        }
                    }
                }
            }
        }

        // parents와 size배열은 기록된 groupId 크기만큼 기록
        parents = new int[groupId];
        size = new int[groupId];
        for(int i = 1; i < groupId; i++){
            parents[i] = i;
            size[i] = 1;
        }
        // 다리 최소 값 구하기
        Collections.sort(bridges, (a,b) -> Integer.compare(a.cost, b.cost));
        int answer = 0;
        int islands = groupId - 2;
        for(Bridge bridge : bridges){
            int start = bridge.start;
            int end = bridge.end;
            int cost = bridge.cost;

            if(find(start) != find(end)){
                union(start, end);
                answer += cost;
                islands -= 1;
            }
        }
        // 섬이 전부 연결되어있는지 확인
        if(islands > 1) return -1;

        return answer;
    }

    private void makeGroup(int[][] map, int x, int y, int groupId){
        q.add(new int[]{x,y});
        map[x][y] = groupId;

        while(!q.isEmpty()){
            int[] curr = q.poll();
            int currX = curr[0];
            int currY = curr[1];

            for(int i = 0; i < 4; i++){
                int nx = currX + dxs[i];
                int ny = currY + dys[i];
                if(inRange(nx,ny) && map[nx][ny] != 0){
                    if(map[nx][ny] != groupId){
                        map[nx][ny] = groupId;
                        q.add(new int[]{nx,ny});
                    }
                }
            }
        }
    }

    private void getBridge(int[][] map,int x, int y, int dir, int groupId){
        int cnt = 1;
        int start  = groupId;
        int end = 0;
        boolean reached = false;
        // 주어진 방향으로 다른 섬이 나올때까지 전진
        while(true){
            if(!inRange(x,y)){
                break;
            }
            if(map[x][y] == groupId) break;
            if(map[x][y] != 0){
                end = map[x][y];
                cnt -= 1;
                reached = true;
                break;
            }
            x += dxs[dir];
            y += dys[dir];
            cnt += 1;
        }

        if(cnt >= 2 && reached){
            // 섬의 groupId에서 -1해서 기록
            bridges.add(new Bridge(start - 1, end - 1, cnt));
        }
    }

    private boolean inRange(int nx, int ny){
        return nx >= 0 && nx < N && ny >= 0 && ny < M;
    }

    private int find(int curr){
        if(parents[curr] == curr) return curr;
        return parents[curr] = find(parents[curr]);
    }

    private void union(int curr1, int curr2){
        int root1 = find(curr1);
        int root2 = find(curr2);

        if(root1 == root2) return;

        if(size[root1] < size[root2]){
            int temp = root1;
            root1 = root2;
            root2 = temp;
        }

        parents[root2] = root1;
        size[root1] += size[root2];
    }
}
```

## 처음 접근

BFS로 연결된 땅을 그룹화하고, 각 섬의 칸에서 상하좌우로 탐색해 가능한 다리를 기록한 다음 크루스칼 알고리즘으로 최소 비용을 구했다.

## 처음 틀렸던 점

- 틀린 원인: 다리 탐색 중 지도 범위를 벗어나는 경우를 확인하지 않았고, 일부 섬만 연결된 최소 신장 숲의 비용을 답으로 반환했으며, 같은 섬을 다시 만난 뒤에도 탐색을 계속해 잘못된 다리를 기록했다.
- 놓친 조건: 모든 섬이 연결되어야 하며, 다리는 중간에 어느 섬도 통과할 수 없다.
- 당시 코드 또는 핵심 부분: 범위 검사 없는 직선 탐색, 전체 연결 여부 검사 누락, `map[x][y] == groupId`일 때 탐색 종료 누락

## 수정 과정

직선 탐색마다 범위를 확인하고, 크루스칼에서 실제로 합쳐진 섬의 수를 세어 전체 연결 여부를 판정했다. 또한 다음 칸이 출발한 섬과 같은 그룹이면 해당 방향의 탐색을 즉시 종료하도록 수정했다.

## 핵심 아이디어

지도를 섬 단위로 그룹화한 뒤 직선으로 연결 가능한 섬 쌍을 가중치 간선으로 변환한다. 이 간선들을 길이순으로 선택하면서 모든 섬을 연결하는 최소 비용을 계산하고, 선택된 간선 수로 전체 연결 여부를 확인한다.

## 복잡도

- 시간 복잡도: O(NM·max(N,M) + E log E), E는 기록한 다리 후보 수
- 공간 복잡도: O(NM + E)

## 반례와 경계 조건

- 최소 입력: 한 칸짜리 섬도 하나의 섬으로 취급한다.
- 최대 입력: N, M이 각각 최대 10이고 섬의 개수는 최대 6이다.
- 실수하기 쉬운 경우: 길이 1인 다리, 일부 섬만 연결되는 경우, 탐색 방향에 출발 섬의 다른 땅이 다시 나타나는 경우, 지도 밖까지 다른 섬을 만나지 못하는 경우

## 한 줄 요약

섬을 그룹화하고 유효한 직선 다리를 간선으로 만든 뒤, 크루스칼의 선택 간선 수까지 확인해 모든 섬의 연결을 보장한다.
