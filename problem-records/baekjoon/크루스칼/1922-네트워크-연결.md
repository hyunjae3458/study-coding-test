# 백준 1922 - 네트워크 연결

## 문제 정보

- 플랫폼: 백준 온라인 저지
- 문제 번호: 1922
- 난이도: 골드 IV (solved.ac, 2026-08-04 확인)
- 문제 링크: https://www.acmicpc.net/problem/1922
- 풀이 날짜: 2026-08-04
- 결과: 정답
- 검증: 로컬 확장 채점 전체 통과 및 백준 반례 찾기 사이트에서 반례 미발견

## 문제 요약

컴퓨터와 컴퓨터를 연결할 수 있는 선과 각 비용이 주어질 때, 모든 컴퓨터가 서로
통신할 수 있도록 연결하는 데 필요한 최소 비용을 구한다. 모든 컴퓨터를 연결할 수
없는 입력은 주어지지 않는다.

## 입출력

- 입력: 컴퓨터 수 `N`, 연결선 수 `M`, 그리고 `M`개의 연결 정보 `A B C`
- 출력: 모든 컴퓨터를 연결하는 최소 비용

## 최종 코드

```java
import java.util.*;

public class Solution {
    int[] parents;

    public long solution(int computerCount, int[][] connections) {
        parents = new int[computerCount + 1];
        Arrays.sort(connections, (a, b) -> Integer.compare(a[2], b[2]));

        for (int i = 1; i < computerCount + 1; i++) {
            parents[i] = i;
        }

        long answer = 0L;
        for (int[] connection : connections) {
            int start = connection[0];
            int end = connection[1];
            int weight = connection[2];

            if (find(start) != find(end)) {
                union(start, end);
                answer += weight;
            }
        }

        return answer;
    }

    private int find(int curr) {
        if (parents[curr] == curr) return curr;
        return parents[curr] = find(parents[curr]);
    }

    private void union(int curr1, int curr2) {
        int root1 = find(curr1);
        int root2 = find(curr2);
        if (root1 != root2) parents[root2] = root1;
    }
}
```

## 처음 접근

연결선을 비용 오름차순으로 정렬하고, 서로 다른 집합에 속한 컴퓨터를 연결하는
선만 선택했다. 컴퓨터들의 연결 여부는 부모 배열을 이용해 관리했다.

## 처음 틀렸던 점

해당 없음. 첫 확장 채점에서 모든 테스트를 통과했다.

## 수정 과정

기록되지 않음. 채점을 위한 코드 수정 없이 통과했다.

## 핵심 아이디어

- 연결 비용이 작은 선부터 확인한다.
- 두 컴퓨터의 대표가 다를 때만 해당 선을 선택한다.
- 선택한 뒤 두 집합을 합친다.
- `find`에 경로 압축을 적용한다.
- 비용 합은 `long`으로 누적한다.

## 복잡도

- 시간 복잡도: `O(M log M)`
- 공간 복잡도: `O(N)` (입력 연결선 배열 제외)

## 반례와 경계 조건

- 컴퓨터가 한 대뿐인 경우
- 컴퓨터가 자기 자신과 연결된 선
- 같은 두 컴퓨터를 연결하는 여러 선
- 모든 연결 비용이 같은 경우
- 이미 연결된 두 집합 사이에 선이 다시 등장하는 경우
- 최대 비용과 최대 입력 규모

## 검증 결과

- 공식 및 고정 테스트 7개: 전부 통과
- 무작위 교차검증 500개: 전부 통과
- 최대 규모 테스트: 통과
- 최대 규모: 컴퓨터 1,000대, 연결선 100,000개
- 최대 규모 기댓값/실제값: `9,990,000` / `9,990,000`
- 백준 반례 찾기 사이트: 반례 미발견

## 한 줄 요약

비용이 작은 연결선부터 확인하면서 서로 다른 집합을 연결하는 선만 선택한다.
