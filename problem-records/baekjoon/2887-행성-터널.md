# 백준 2887 - 행성 터널

## 문제 정보

- 플랫폼: 백준 온라인 저지
- 문제 번호: 2887
- 난이도: 플래티넘 V (solved.ac, 2026-08-05 확인)
- 문제 링크: https://www.acmicpc.net/problem/2887
- 풀이 날짜: 2026-08-05
- 결과: 로컬 확장 채점 통과

## 문제 요약

3차원 좌표에 있는 모든 행성을 터널로 연결할 때 필요한 최소 비용을 구한다. 두 행성
사이의 터널 비용은 세 좌표 차이의 절댓값 중 최솟값이다.

## 입출력

- 입력: 행성 수 `N`과 각 행성의 `x`, `y`, `z` 좌표
- 출력: 모든 행성을 연결하는 데 필요한 최소 비용

### 예제 입력

```text
5
11 -15 -15
14 -5 -15
-1 -1 -5
10 -4 -1
19 -4 19
```

### 예제 출력

```text
4
```

## 최종 Solution 코드

```java
import java.util.*;
public class Solution {
    class Node{
        int start;
        int end;
        int cost;
        public Node(int start, int end, int cost){
            this.start = start;
            this.end = end;
            this.cost = cost;
        }
    }

    class Node2{
        int num;
        int pos;
        public Node2(int num, int pos){
            this.num = num;
            this.pos = pos;
        }
    }

    int[] parents;
    int[] size;
    public long solution(int[][] planets) {
        parents = new int[planets.length];
        size = new int[planets.length];
        for(int i = 0; i < planets.length;i ++){
            parents[i] = i;
            size[i] = 1;
        }
        List<Node2> lst1 = new ArrayList<>();
        List<Node2> lst2 = new ArrayList<>();
        List<Node2> lst3 = new ArrayList<>();

        for(int i = 0; i < planets.length; i++){
            lst1.add(new Node2(i,planets[i][0]));
            lst2.add(new Node2(i,planets[i][1]));
            lst3.add(new Node2(i,planets[i][2]));
        }

        Collections.sort(lst1, (a,b) -> Integer.compare(a.pos, b.pos));
        Collections.sort(lst2, (a,b) -> Integer.compare(a.pos, b.pos));
        Collections.sort(lst3, (a,b) -> Integer.compare(a.pos, b.pos));

        List<Node> loadList = new ArrayList<>();

        for(int i = 1; i < lst1.size(); i++){
            int diff1 = Math.abs(lst1.get(i).pos - lst1.get(i-1).pos);
            int diff2 = Math.abs(lst2.get(i).pos - lst2.get(i-1).pos);
            int diff3 = Math.abs(lst3.get(i).pos - lst3.get(i-1).pos);
            loadList.add(new Node(lst1.get(i).num, lst1.get(i-1).num, diff1));
            loadList.add(new Node(lst2.get(i).num, lst2.get(i-1).num, diff2));
            loadList.add(new Node(lst3.get(i).num, lst3.get(i-1).num, diff3));
        }

        Collections.sort(loadList, (a,b) -> Integer.compare(a.cost, b.cost));

        long answer = 0L;
        for(int i = 0; i < loadList.size(); i++){
            int start = loadList.get(i).start;
            int end = loadList.get(i).end;
            int cost = loadList.get(i).cost;

            if(find(start) != find(end)){
                union(start,end);
                answer += cost;
            }
        }

        return answer;
    }

    private int find(int curr){
        if(parents[curr] == curr) return curr;
        return parents[curr] = find(parents[curr]);
    }

    private void union(int curr1, int curr2){
        int root1 = find(curr1);
        int root2 = find(curr2);

        if(root1 == root2) return;

        if(size[root1] < size[root2]){
            int temp = root1;
            root1 = root2;
            root2 = temp;
        }

        parents[root2] = root1;
        size[root1] += size[root2];
    }
}
```

## 처음 접근

각 좌표축별로 행성을 정렬하고, 각 축에서 서로 인접한 행성 사이의 간선만 후보로
만들었다. 후보 간선을 비용순으로 정렬한 뒤 서로소 집합을 이용한 크루스칼 알고리즘을
적용했다.

## 처음 틀렸던 점

- Union by size를 사용하면서 각 집합의 초기 크기를 `0`으로 설정했다.
- 합친 뒤에도 크기가 계속 `0`이라 크기 비교가 작동하지 않았다.
- 특정 최대 규모 입력에서 부모 트리가 깊어져 재귀 `find`가 `StackOverflowError`를 일으켰다.

당시 핵심 부분:

```java
size[i] = 0;
```

## 수정 과정

각 행성은 처음에 원소 하나인 집합이므로 초기 크기를 `1`로 수정했다. 이후 작은 집합의
루트를 큰 집합 아래에 연결하도록 크기 비교가 정상 동작했고, 이전 실패 테스트를 통과했다.

## 핵심 아이디어

- 각 좌표축에서 정렬상 인접한 행성 사이의 간선만 후보로 만든다.
- 후보 간선을 비용순으로 정렬하고 크루스칼 알고리즘으로 최소 신장 트리를 구성한다.
- 경로 압축과 Union by size로 서로소 집합 연산을 효율적으로 처리한다.
- 전체 비용은 `long`으로 누적한다.

## 복잡도

- 시간 복잡도: `O(N log N)`
- 공간 복잡도: `O(N)`

## 반례와 경계 조건

- 행성이 하나뿐인 경우
- 좌표가 모두 같은 행성이 있는 경우
- 음수 좌표와 좌표 최솟값·최댓값
- 특정 좌표축 값이 같은 행성이 여러 개인 경우
- 서로 다른 좌표축의 인접 관계가 각각 중요한 경우
- 입력 순서에 따라 부모 트리가 한쪽으로 깊어질 수 있는 경우
