# 백준 6497 - 전력난

## 문제 정보

- 플랫폼: 백준 온라인 저지
- 문제 번호: 6497
- 난이도: 골드 IV (solved.ac, 2026-08-05 확인)
- 문제 링크: https://www.acmicpc.net/problem/6497
- 풀이 날짜: 2026-08-05
- 결과: 로컬 확장 채점 통과

## 문제 요약

모든 집 사이를 켜진 길만으로 왕래할 수 있게 유지하면서, 꺼도 되는 길의 비용 합을
최대로 만든다. 여러 테스트 케이스가 주어지며 `0 0`에서 입력이 끝난다.

## 입출력

- 입력: 집의 수 `m`, 길의 수 `n`, 그리고 `n`개의 길 `x y z`
- 출력: 각 테스트 케이스에서 절약할 수 있는 최대 비용

## 최종 제출 코드

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.Arrays;

public class Main {
    private static int[] parents;
    private static int[] size;

    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        StringBuilder answer = new StringBuilder();

        while (true) {
            int houseCount = scanner.nextInt();
            int roadCount = scanner.nextInt();
            if (houseCount == 0 && roadCount == 0) break;

            int[][] roads = new int[roadCount][3];
            for (int i = 0; i < roadCount; i++) {
                roads[i][0] = scanner.nextInt();
                roads[i][1] = scanner.nextInt();
                roads[i][2] = scanner.nextInt();
            }

            if (answer.length() > 0) answer.append('\n');
            answer.append(solution(houseCount, roads));
        }
        System.out.print(answer);
    }

    private static long solution(int houseCount, int[][] roads) {
        parents = new int[houseCount];
        size = new int[houseCount];
        for (int i = 0; i < houseCount; i++) {
            parents[i] = i;
            size[i] = 1;
        }

        Arrays.sort(roads, (a, b) -> Integer.compare(a[2], b[2]));
        long totalCost = 0;
        long minimumCost = 0;

        for (int[] road : roads) {
            totalCost += road[2];
            if (find(road[0]) != find(road[1])) {
                union(road[0], road[1]);
                minimumCost += road[2];
            }
        }
        return totalCost - minimumCost;
    }

    private static int find(int current) {
        if (parents[current] == current) return current;
        return parents[current] = find(parents[current]);
    }

    private static void union(int first, int second) {
        int firstRoot = find(first);
        int secondRoot = find(second);
        if (firstRoot == secondRoot) return;

        if (size[firstRoot] < size[secondRoot]) {
            int temp = firstRoot;
            firstRoot = secondRoot;
            secondRoot = temp;
        }
        parents[secondRoot] = firstRoot;
        size[firstRoot] += size[secondRoot];
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int index;
        private int size;

        private int read() throws IOException {
            if (index >= size) {
                size = input.read(buffer);
                index = 0;
                if (size == -1) return -1;
            }
            return buffer[index++];
        }

        private int nextInt() throws IOException {
            int character;
            do {
                character = read();
            } while (character <= ' ' && character != -1);

            int value = 0;
            while (character > ' ') {
                value = value * 10 + character - '0';
                character = read();
            }
            return value;
        }
    }
}
```

## 처음 접근

모든 길의 비용을 더한 뒤 크루스칼 알고리즘으로 최소 신장 트리의 비용을 구하고,
전체 비용에서 최소 신장 트리 비용을 빼 절약할 수 있는 최대 비용을 계산했다. 집합은
경로 압축과 크기 기준 합치기를 사용하는 서로소 집합으로 관리하려 했다.

## 처음 틀렸던 점

- 크기가 작은 트리를 큰 트리에 붙이기 위해 루트를 교환해야 하는 곳에서 `size` 값만
  서로 교환했다.
- 실제 부모 연결은 계속 같은 방향으로 이루어져 특정 입력에서 부모 트리가 매우 깊어졌다.
- 집 200,000개를 역방향으로 연속 연결한 테스트에서 재귀 `find`가
  `StackOverflowError`를 일으켰다.

당시 핵심 부분:

```java
if (size[root1] < size[root2]) {
    int temp = size[root1];
    size[root1] = size[root2];
    size[root2] = temp;
}
parents[root2] = root1;
```

## 수정 과정

`size` 배열의 값을 교환하는 대신 `root1`과 `root2`를 교환했다. 그 결과 작은 집합의
루트가 큰 집합의 루트 아래에 연결되어 부모 트리의 깊이가 제한되었다. 수정 후 기존
실패 테스트와 최대 규모 테스트를 다시 통과했다.

## 핵심 아이디어

- 모든 길의 비용 합을 구한다.
- 비용이 작은 길부터 서로 다른 집합을 연결해 최소 신장 트리를 만든다.
- 전체 길의 비용에서 최소 신장 트리 비용을 빼 최대 절약 비용을 계산한다.
- 경로 압축과 Union by size로 서로소 집합 연산을 효율적으로 수행한다.
- 비용의 합은 `long`으로 누적한다.

## 복잡도

- 시간 복잡도: `O(N log N)` (`N`은 길의 수)
- 공간 복잡도: `O(M)` (`M`은 집의 수, 입력 길 배열 제외)

## 반례와 경계 조건

- 집 하나와 길이 없는 경우
- 두 집 사이에 길이 하나 또는 여러 개 있는 경우
- 비용이 0인 길이 있는 경우
- 이미 트리 형태라 절약 비용이 0인 경우
- 모든 길의 비용이 큰 경우와 비용 합이 `int` 범위를 넘는 경우
- 입력 간선 방향에 따라 부모 트리가 한쪽으로 깊어질 수 있는 경우
- 여러 테스트 케이스 처리와 종료 입력 `0 0`
