# 백준 1197 - 최소 스패닝 트리 (크루스칼)

## 문제 정보

- 플랫폼: 백준 온라인 저지
- 문제 번호: 1197
- 난이도: 골드 IV (solved.ac, 2026-08-04 확인)
- 문제 링크: https://www.acmicpc.net/problem/1197
- 풀이 날짜: 2026-08-03
- 결과: 정답
- 검증: 로컬 확장 채점 전체 통과 및 백준 반례 찾기 사이트에서 반례 미발견
- 비고: 같은 문제를 프림에 이어 크루스칼 방식으로 다시 풀이함

## 문제 요약

가중치가 있는 연결된 무방향 그래프에서 모든 정점을 연결하고, 선택한 간선의
가중치 합이 최소가 되는 스패닝 트리의 가중치 합을 구한다.

## 입출력

- 입력: 정점 수 `V`, 간선 수 `E`와 `E`개의 간선 `A B C`
- 출력: 최소 스패닝 트리의 가중치 합

연습 템플릿에서는 다음 함수 형태로 변환했다.

```java
public long solution(int vertexCount, int[][] edges)
```

## 최종 코드

```java
import java.util.*;

public class Solution {
    int[] parents;

    public long solution(int vertexCount, int[][] edges) {
        parents = new int[vertexCount + 1];
        Arrays.sort(edges, (a, b) -> Integer.compare(a[2], b[2]));

        for (int i = 1; i < parents.length; i++) {
            parents[i] = i;
        }

        long answer = 0L;
        for (int[] edge : edges) {
            int start = edge[0];
            int end = edge[1];
            int weight = edge[2];

            if (find(start) != find(end)) {
                answer += weight;
                union(start, end);
            }
        }

        return answer;
    }

    private int find(int curr) {
        if (parents[curr] == curr) {
            return curr;
        }
        return parents[curr] = find(parents[curr]);
    }

    private void union(int curr1, int curr2) {
        int parent1 = find(curr1);
        int parent2 = find(curr2);
        parents[parent2] = parent1;
    }
}
```

## 처음 접근

모든 간선을 가중치가 작은 순서로 정렬한 뒤, 서로 다른 집합에 속한 두 정점을
잇는 간선만 선택했다. 정점들의 연결 상태는 부모 배열을 사용하는 서로소 집합으로
관리했다.

## 처음 틀렸던 점

해당 없음. 첫 채점에서 준비한 모든 테스트를 통과했다.

## 수정 과정

기록되지 않음. 채점을 위한 코드 수정 없이 통과했다.

## 핵심 아이디어

- 간선을 가중치 오름차순으로 정렬한다.
- 각 정점이 속한 집합의 대표를 `find`로 확인한다.
- 두 정점의 대표가 다를 때만 간선을 선택하고 두 집합을 합친다.
- `find`에 경로 압축을 적용한다.
- 최종 합은 `long`으로 누적한다.

## 복잡도

- 시간 복잡도: 간선 정렬을 포함해 `O(E log E)`
- 공간 복잡도: `O(V)` (입력 간선 배열 제외)

## 반례와 경계 조건

- 정점이 하나이고 간선이 없는 경우
- 음수 가중치가 포함된 경우
- 같은 두 정점 사이에 평행 간선이 존재하는 경우
- 이미 같은 집합에 속한 두 정점을 잇는 간선이 등장하는 경우
- 최소 스패닝 트리의 가중치 합이 `int` 범위를 벗어나는 경우
- 정점 10,000개와 간선 100,000개의 최대 규모 입력

## 검증 결과

- 공식 및 고정 테스트 7개: 전부 통과
- 무작위 교차검증 300개: 전부 통과
- 최대 규모 테스트: 통과
- 최대 규모 가중치 기댓값/실제값: `9,999,000,000` / `9,999,000,000`
- 백준 반례 찾기 사이트: 반례 미발견

## 한 줄 요약

가중치가 작은 간선부터 확인하면서 서로 다른 집합을 연결하는 간선만 선택한다.
