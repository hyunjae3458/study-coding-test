## 문제 요약

M초마다 K개씩 생산하는 붕어빵을 모든 손님에게 도착 즉시 제공할 수 있는지 판단한다.

## 입출력

- 입력: T, 각 사례의 N M K와 N명의 도착 시각. N,M,K는 1~100, 시각은 0~11,111.
- 출력: `#테스트번호 Possible` 또는 `#테스트번호 Impossible`.
- 공식 예제는 examples/swea/1860/의 보관본이다. 사용자 작업용 input.txt는 수정하지 않았다.

### 예제 입력

```text
4
2 2 2
3 4
2 2 2
1 2
2 2 1
4 2
2 2 1
3 2
```

### 예제 출력

```text
#1 Possible
#2 Impossible
#3 Possible
#4 Impossible
```

## 최종 Solution 코드

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

class Solution {
    public static void main(String args[]) throws Exception {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(bf.readLine());

        for (int testCase = 1; testCase <= T; testCase++) {
            StringTokenizer st = new StringTokenizer(bf.readLine());
            // 손님 수
            int N = Integer.parseInt(st.nextToken());
            // 초
            int M = Integer.parseInt(st.nextToken());
            // 개수
            int K = Integer.parseInt(st.nextToken());

            int[] reserve = new int[N];
            st = new StringTokenizer(bf.readLine());
            for(int i = 0; i < N; i++){
                reserve[i] = Integer.parseInt(st.nextToken());
            }
            // 먼저 온 사람으로 정렬
            Arrays.sort(reserve);
            boolean possible = true;

            for(int i = 0; i < N; i++){
                int produced = (reserve[i] / M) * K;

                if(produced < i + 1){
                    possible = false;
                    break;
                }
            }

            System.out.println("#" + testCase + " " + (possible ? "Possible" : "Impossible"));
        }
    }
}
```

## 핵심 아이디어

손님을 도착 시각 순으로 처리한다. i번째 손님까지 제공하려면 도착 시점의 누적 생산량 `(reserve[i] / M) * K`가 `i + 1` 이상이어야 한다. 하나라도 부족하면 해당 손님이 기다려야 하므로 불가능하다. 모든 시점에서 충분하면 먼저 온 손님부터 제공할 수 있다.

## 복잡도

- 시간 복잡도: O(N log N). 정렬 후 O(N) 순회.
- 공간 복잡도: O(N). 입력 배열 포함.

## 반례와 경계 조건

- 최소 입력: 손님 1명이 0초에 오면 불가능, 첫 생산 시각에 오면 가능.
- 최대 입력: N=100, 도착 시각 11,111.
- 같은 시각에 여러 손님이 몰려 누적 생산량을 초과하는 경우.
- 도착 시각이 정렬되어 있지 않은 입력, 생산 시각 직전·정확히 일치하는 시각.

## 두 풀이 비교

마지막 도착 시각을 L이라 한다.

| 항목 | 시뮬레이션 | 그리디 |
|---|---|---|
| 확인 대상 | 매초 생산과 손님 방문 | 손님 도착 시점의 누적 생산량 |
| 시간 복잡도 | O(N log N + L) | O(N log N) |
| 공간 복잡도 | O(N + L) | O(N) |
| 저장 상태 | 시간별 방문자 수, 재고, 제공 인원 | 정렬한 도착 시각, 가능 여부 |
| 확인 상태 | 온라인 정답 | 로컬 확장 채점 통과 |
