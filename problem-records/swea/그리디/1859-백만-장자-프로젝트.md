## 문제 요약

N일의 매매가를 알고 있을 때, 하루 최대 1개를 구입하고 판매 수량에는 제한이 없는 조건에서 최대 이익을 구한다.

## 입출력

- 입력: T, 각 사례의 N과 날짜 순서의 매매가 N개. 2 ≤ N ≤ 1,000,000, 매매가는 1~10,000.
- 출력: `#테스트번호 최대이익`.

### 예제 입력

```text
3
3
10 7 6
3
3 5 9
5
1 1 3 1 2
```

### 예제 출력

```text
#1 0
#2 10
#3 5
```

## 최종 Solution 코드

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

class Solution {
    public static void main(String args[]) throws Exception {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(bf.readLine());

        for (int testCase = 1; testCase <= T; testCase++) {
            StringTokenizer st = new StringTokenizer(bf.readLine());
            int N = Integer.parseInt(st.nextToken());
            st = new StringTokenizer(bf.readLine());
            int[] price = new int[N];
            for(int i = 0; i < N; i++){
                price[i] = Integer.parseInt(st.nextToken());
            }
            int currPrice = price[N-1];
            long answer = 0;
            for(int i = N - 2; i >= 0; i--){
                if(currPrice > price[i]){
                    answer += currPrice - price[i];

                } else{
                    currPrice = price[i];
                }
            }

            System.out.println("#" + testCase + " " + answer);
        }
    }
}
```

## 핵심 아이디어

뒤에서부터 보면서 현재 가격이 이후 최고 가격보다 낮으면 그 차이를 이익에 더한다. 더 높거나 같은 가격을 만나면 최고 가격을 갱신한다. 하루 구매량은 최대 1개이고 판매 수량에 제한이 없어 각 구매일의 최선의 판매 이익을 합산할 수 있다.

## 복잡도

- 시간 복잡도: 테스트 케이스당 O(N).
- 공간 복잡도: O(N). 가격 배열과 입력 문자열을 포함하며, 순회 자체의 추가 상태는 O(1).

## 반례와 경계 조건

- 최소 입력: N=2에서 상승·하락·동일 가격.
- 최대 입력: 가격 1이 999,999일 이어지고 마지막 가격이 10,000이면 이익은 9,998,990,001이다.
- 이익은 int 범위를 넘을 수 있어 long으로 누적한다.
- 계속 하락하거나 모든 가격이 같으면 이익은 0이다.
- 여러 봉우리와 반복 최고 가격이 있는 경우를 확인한다.
