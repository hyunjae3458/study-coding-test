## 문제 요약

모든 비트가 0인 메모리를 주어진 비트열로 복구한다. 한 위치의 값을 정하면 그 위치부터 끝까지 같은 값으로 덮어쓴다. 필요한 최소 수정 횟수를 구한다.

## 입출력

- 입력: T와 각 테스트 케이스의 비트열. 길이는 1~50이다.
- 출력: `#테스트번호 최소수정횟수`.

### 예제 입력

```text
2
0011
100
```

### 예제 출력

```text
#1 1
#2 2
```

## 최종 Solution 코드

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

class Solution {
    public static void main(String args[]) throws Exception {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(bf.readLine());

        for (int testCase = 1; testCase <= T; testCase++) {
            String bit = bf.readLine();
            int answer = 0;
            char before = '0';
            for(int i = 0; i < bit.length(); i++){
                if(before != bit.charAt(i)){
                    answer += 1;
                    before = bit.charAt(i);
                }
            }
            System.out.println("#" + testCase + " " + answer);
        }

    }
}
```

## 핵심 아이디어

초기 상태를 나타내는 before를 '0'으로 둔다. 목표 비트와 다를 때 수정 횟수를 늘리고 before를 갱신한다. 앞에서 확정한 비트를 유지하며 필요한 수정만 수행한다.

## 복잡도

- 시간 복잡도: 비트열 길이를 L이라 할 때 O(L).
- 공간 복잡도: 입력 문자열 포함 O(L), 추가 작업 공간 O(1).

## 반례와 경계 조건

- 최소 입력: 0은 0회, 1은 1회.
- 최대 입력: 길이 50, 1로 시작하는 교대 비트열은 50회.
- 실수하기 쉬운 경우: 선행 0, 전체 0, 전체 1, 여러 테스트 케이스의 상태 초기화.
