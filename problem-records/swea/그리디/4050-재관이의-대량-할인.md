## 문제 요약

옷 세 벌을 묶어 구매하면 그 묶음에서 가장 저렴한 한 벌이 무료다. 모든 옷을 구매할 때 최소 결제 금액을 구한다. 세 벌 미만으로 남은 옷에는 할인이 없다.

## 입출력

- 입력: 테스트 케이스 수 T, 각 사례의 옷 개수 N, 다음 줄에 N개 가격.
- 출력: `#테스트번호 최소구매비용`.

### 예제 입력

자체 예제 (현재 input.txt):

```text
1
3
1 2 3
```

### 예제 출력

자체 예제 (현재 output.txt):

```text
#1 5
```

## 최종 Solution 코드

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

class Solution {
    public static void main(String args[]) throws Exception {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(bf.readLine());

        for (int testCase = 1; testCase <= T; testCase++) {
            StringTokenizer st = new StringTokenizer(bf.readLine());
            int N = Integer.parseInt(st.nextToken());
            int[] price = new int[N];

            int totalPrice = 0;
            st = new StringTokenizer(bf.readLine());
            for(int i = 0; i < N; i++){
                int p = Integer.parseInt(st.nextToken());
                price[i] = p;
                totalPrice += p;
            }
            Arrays.sort(price);
            int[] sortedPrice = new int[N];
            for(int i = 0; i < N; i++){
                sortedPrice[i] = price[N - 1 - i];
            }
            int discountCnt = price.length / 3;
            int answer = 0;
            for(int i = 2; i < N; i += 3){
                answer += sortedPrice[i];
                discountCnt -= 1;
                if(discountCnt == 0){
                    break;
                }
            }

            totalPrice -= answer;

            System.out.println("#" + testCase + " " + totalPrice);
        }
    }
}
```

## 처음 접근

처음 확인한 작성 중 코드는 가격을 오름차순 정렬한 뒤 가장 작은 가격부터 N/3개를 전체 합에서 빼는 방식이었다. 해당 버전에 대한 실제 제출 결과는 기록되지 않았다.

## 처음 틀렸던 점

- 확인된 초기 작성 코드에서는 가장 싼 N/3벌을 무조건 무료로 계산했다. 이 방식은 최대 할인을 보장하지 않는다. 가격이 1,2,3,4,5,6일 때 이 방식의 금액은 18이지만 최소 금액은 16이다.
- 초기 입력 코드는 N을 읽은 StringTokenizer에서 가격까지 읽었다. 최종 코드에서는 다음 줄을 새 StringTokenizer로 읽도록 변경되어 있다.
- 초기 코드의 핵심 부분:

```java
            Arrays.sort(price);
            int discountCnt = price.length / 3;
            for(int i = 0; i < discountCnt; i++){
                totalPrice -= price[i];
            }
```

위 내용은 세팅 중 확인한 실제 사용자 작성 코드의 변화이며 온라인 오답 제출 이력을 의미하지 않는다.

## 수정 과정

사용자가 가격 입력 줄을 별도로 읽고, 정렬된 배열을 뒤집은 sortedPrice를 추가했다. 내림차순 배열의 인덱스 2,5,8,...에 해당하는 값을 할인액으로 합산하도록 변경했다. 이후 사용자가 온라인 통과를 알려주었다. 기록 과정에서 에이전트는 사용자 코드를 수정하지 않았다.

## 핵심 아이디어

비싼 옷부터 세 벌씩 묶으면 각 묶음에서 무료로 받을 수 있는 가격을 크게 만들 수 있다. 전체 금액에서 각 묶음의 세 번째 가격을 빼서 최소 결제 금액을 구한다.

## 복잡도

- 시간 복잡도: O(N log N). 정렬 후 배열 복사와 할인 계산은 O(N).
- 공간 복잡도: O(N). price와 sortedPrice 배열을 저장한다.

## 반례와 경계 조건

- 최소 크기: N=1 또는 N=2에서는 할인하지 않는다.
- N이 3의 배수가 아니면 남은 옷의 금액은 그대로 포함한다.
- 모든 가격이 같거나 가격이 오름차순·내림차순으로 주어지는 경우.
- 1,2,3,4,5,6의 최소 결제 금액은 16이다.
- 큰 입력 검증: N=100,000이고 가격이 모두 100일 때 결과는 6,666,700.
- 공식 가격 상한은 이번 기록에서 확인하지 않았으며 임의로 기재하지 않았다.

## 한 줄 요약

비싼 순서로 세 벌씩 묶고 각 묶음의 가장 싼 한 벌을 전체 금액에서 뺀다.
