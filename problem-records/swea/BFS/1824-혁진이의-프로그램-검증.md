# SWEA 1824 - 혁진이의 프로그램 검증

## 문제 정보

- 플랫폼: SWEA
- 문제 번호: 1824
- 난이도: D4 (SWEA, 2026-08-28 확인)
- 문제 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV4yLUiKDUoDFAUx
- 풀이 날짜: 2026-08-28
- 결과: 온라인 정답

## 문제 요약

R×C 격자에 작성된 프로그램을 (0, 0)에서 오른쪽 방향, 메모리 값 0으로 실행한다. 각 문자는 이동 방향이나 메모리 값을 바꾸며, 격자 밖으로 이동하면 반대편으로 이어진다. `?`에서는 네 방향 중 하나를 무작위로 선택할 수 있다. 가능한 실행 경로 중 하나라도 `@`를 실행하여 정지할 수 있는지 판별한다.

## 입출력

- 입력: 첫 줄에 테스트 케이스 수 T가 주어진다. 각 테스트 케이스마다 행 R, 열 C와 공백 없이 이어진 R줄의 프로그램이 주어진다.
- 출력: 정지할 가능성이 있으면 `#테스트번호 YES`, 없으면 `#테스트번호 NO`를 출력한다.

### 예제 입력

```text
3
2 6
6>--v.
.^--_@
2 6
5>--v.
.^--_@
2 6
.>--v.
.^--?@
```

### 예제 출력

```text
#1 YES
#2 NO
#3 YES
```

## 최종 Solution 코드

```java
import java.util.*;

public class Solution {
    /**
     * @param rows 프로그램 영역의 행 크기 R (입력값 그대로)
     * @param columns 프로그램 영역의 열 크기 C (입력값 그대로)
     * @param program R×C 프로그램 명령 문자 (입력값 그대로)
     * @return 프로그램이 정지 명령어(@)를 실행할 가능성이 있으면 true
     */
    class Node{
        int x;
        int y;
        int dir;
        int val;
        public Node(int x, int y, int dir, int val){
            this.x = x;
            this.y = y;
            this.dir = dir;
            this.val = val;
        }
    }

    class State{
        int dir;
        int val;
        public State(int dir, int val){
            this.dir = dir;
            this.val = val;
        }
    }

    // 우 하 좌 상
    int[] dxs = {0,1,0,-1};
    int[] dys = {1,0,-1,0};
    boolean[][][][] path;
    int N;
    int M;
    public boolean solution(int rows, int columns, char[][] program) {
        // x y val dir
        path = new boolean[rows][columns][16][4];
        N = rows;
        M = columns;
        boolean noArrive = true;

        for(char[] p : program){
            for(char c : p){
                if(c == '@'){
                    noArrive = false;
                }
            }
        }

        if(noArrive) return false;

        Queue<Node> q = new LinkedList<>();
        q.add(new Node(0,0,0,0));
        path[0][0][0][0] = true;
        while(!q.isEmpty()){
            Node curr = q.poll();
            int currX = curr.x;
            int currY = curr.y;
            int dir = curr.dir;
            int val = curr.val;


            if(program[currX][currY] == '@'){
                return true;
            }


            if(program[currX][currY] == '?'){
                for(int i = 0; i < 4; i++){

                    int nx = (currX + dxs[i] + N) % N;
                    int ny = (currY + dys[i] + M) % M;

                    if(!path[nx][ny][val][i]){
                        path[nx][ny][val][i] = true;
                        q.add(new Node(nx,ny,i,val));
                    }
                }
            }
            else{
                State nextState = commands(val, dir, program[currX][currY]);

                int nx = (currX + dxs[nextState.dir] + N) % N;
                int ny = (currY + dys[nextState.dir] + M) % M;
                if(!path[nx][ny][nextState.val][nextState.dir]){
                    path[nx][ny][nextState.val][nextState.dir] = true;
                    q.add(new Node(nx,ny,nextState.dir, nextState.val));
                }


            }
        }
        return false;
    }

    private State commands(int val, int dir, char command){
        if(command == '>'){
            dir = 0;
        }
        if(command == '<'){
            dir = 2;
        }
        if(command == '^'){
            dir = 3;
        }
        if(command == 'v'){
            dir = 1;
        }
        if(command == '_'){
            if(val == 0){
                dir = 0;
            } else{
                dir = 2;
            }
        }
        if(command == '|'){
            if(val == 0){
                dir = 1;
            } else{
                dir = 3;
            }
        }
        if(Character.isDigit(command)){
            val = command - '0';
        }
        if(command == '+'){
            val += 1;
            if(val > 15){
                val = 0;
            }
        }
        if(command == '-'){
            val -= 1;
            if(val < 0){
                val = 15;
            }
        }

        return new State(dir, val);
    }
}
```

## 처음 접근

현재 위치, 진행 방향, 메모리 값을 상태로 두고 재귀 DFS로 가능한 경로를 탐색했다. 동일한 위치라도 방향과 메모리 값이 다르면 이후 실행 결과가 달라질 수 있으므로 `path[행][열][메모리][방향]`의 4차원 방문 배열을 사용했다. `?`에서는 네 방향을 모두 재귀적으로 탐색했다.

## 처음 틀렸던 점

- 틀린 원인 1: 격자 경계를 넘어갈 때 `(좌표 + 변화량) % 크기`로 계산했다. Java에서는 음수의 나머지가 음수이므로 위쪽이나 왼쪽으로 넘어가면 좌표가 -1이 되었다.
- 당시 핵심 부분:

```java
int nx = (x + dxs[dir]) % N;
int ny = (y + dys[dir]) % M;
```

- 틀린 원인 2: 재귀 DFS의 상태 수가 최대 `20 × 20 × 16 × 4 = 25,600`개이고, `?`가 많은 입력에서는 재귀 깊이가 커져 `StackOverflowError`가 발생했다.
- 재현 입력의 핵심: 20×20 격자가 거의 전부 `?`인 경우.
- 틀린 원인 3: BFS로 변경한 직후 이미 방문한 상태를 꺼내면 `return false`로 전체 탐색을 종료했다. 이 때문에 `?`에서 만들어진 다른 유효한 분기들을 확인하지 못했다.
- 당시 핵심 부분:

```java
if(path[currX][currY][val][dir]){
    return false;
}
```

- 틀린 원인 4: `?`에서 네 방향으로 이동하면서 큐의 새 노드에는 선택된 방향 `i`가 아니라 기존 방향 `dir`을 저장했다.
- 당시 핵심 부분:

```java
q.add(new Node(nx, ny, dir, val));
```

## 수정 과정

1. 경계 순환 좌표를 `(현재 좌표 + 변화량 + 크기) % 크기`로 계산해 음수 좌표를 방지했다.
2. 최대 상태 수에서 Java 재귀 스택이 터질 수 있으므로 재귀 DFS를 큐 기반 BFS로 변경했다.
3. 프로그램에 `@`가 하나도 없으면 탐색 전에 즉시 `false`를 반환하도록 했다.
4. 방문한 상태를 만났을 때 전체 탐색을 종료하지 않고, 새 상태를 큐에 넣기 전에 방문 여부를 검사하도록 변경했다.
5. `?`의 각 분기에서 위치뿐 아니라 선택된 방향 `i`도 새 상태에 정확히 저장했다.
6. 20×20 `?` 격자에서 `@`가 있는 경우와 없는 경우를 각각 검사한 뒤 SWEA 온라인 정답을 확인했다.

## 핵심 아이디어

- 프로그램 실행 상태는 `(행, 열, 메모리 값, 방향)` 네 요소로 결정된다.
- 가능한 상태 수는 유한하므로 동일한 네 요소의 상태는 다시 탐색하지 않는다.
- `?`는 확률 계산 문제가 아니라 정지 가능한 실행이 하나라도 존재하는지 묻기 때문에 네 방향을 모두 분기한다.
- 각 명령을 적용한 다음 반대편으로 이어지는 좌표를 계산하고, 처음 보는 다음 상태만 큐에 넣는다.
- BFS와 DFS 중 어느 탐색 순서를 사용해도 가능성 판별 결과는 같지만, Java에서는 반복형 BFS가 재귀 스택 제한으로부터 안전하다.

## 복잡도

- 시간 복잡도: 가능한 상태가 최대 `R × C × 16 × 4`개이고 각 상태에서 최대 네 방향을 확인하므로 `O(R × C × 16 × 4)`
- 공간 복잡도: 4차원 방문 배열과 큐에 상태를 저장하므로 `O(R × C × 16 × 4)`

## 반례와 경계 조건

- 프로그램에 `@`가 전혀 없으면 반드시 `NO`이다.
- 위쪽 또는 왼쪽 경계를 넘어갈 때 Java의 음수 나머지를 그대로 사용하면 안 된다.
- 같은 칸이라도 메모리 값이나 진행 방향이 다르면 서로 다른 상태다.
- `?`에서는 네 방향 중 하나만 고르는 것이 아니라 네 가능성을 모두 탐색해야 한다.
- 중복 상태 하나를 발견했다고 전체 탐색을 종료하면 다른 큐의 분기를 놓친다.
- 메모리 값은 `+`에서 15 다음 0으로, `-`에서 0 다음 15로 순환한다.
- 20×20 전체가 `?`에 가까운 입력은 재귀 깊이와 상태 방문 처리를 검증하기 좋은 경계 테스트다.

## 한 줄 요약

행·열·메모리·방향을 하나의 상태로 묶어 BFS로 탐색하고, `?`의 네 분기와 격자 순환 이동을 모두 정확히 처리한다.
