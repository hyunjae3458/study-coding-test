## 문제 요약

지도에 있는 전차가 이동·발사 명령을 순서대로 수행한 후의 지도 상태를 출력한다. 평지로 이동할 수 있고, 포탄은 벽돌을 파괴하지만 강철 벽은 파괴하지 못한다.

## 입출력

- 입력: T, 각 사례의 H W, H줄 지도, 명령 수 N과 명령 문자열. 2 ≤ H,W ≤ 20, 1 ≤ N ≤ 100.
- 출력: `#테스트번호 ` 뒤에 첫 행을 이어 쓰고 총 H줄의 지도를 출력한다.

### 예제 입력

```text
1
3 7
***....
*-..#**
#<.****
23
SURSSSSUSLSRSSSURRDSRDS
```

### 예제 출력

```text
#1 **....v
.-..#..
#......
```

## 최종 Solution 코드

사용자의 요청에 따라 리팩토링한 현재 src/Solution.java 전체이다. 온라인 통과 원본은 위 링크에 별도로 보존했다.

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.StringTokenizer;

class Solution {
    static int[] dxs = {1,0,-1,0};
    static int[] dys = {0,1,0,-1};
    public static void main(String args[]) throws Exception {
        //.	평지(전차가 들어갈 수 있다.)
        //*	벽돌로 만들어진 벽
        //#	강철로 만들어진 벽
        //-	물(전차는 들어갈 수 없다.)
        //^	위쪽을 바라보는 전차(아래는 평지이다.)
        //v	아래쪽을 바라보는 전차(아래는 평지이다.)
        //<	왼쪽을 바라보는 전차(아래는 평지이다.)
        //>	오른쪽을 바라보는 전차(아래는 평지이다.)

        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(bf.readLine());

        for (int testCase = 1; testCase <= T; testCase++) {
            StringTokenizer st = new StringTokenizer(bf.readLine());
            int H = Integer.parseInt(st.nextToken());
            int W = Integer.parseInt(st.nextToken());
            // 게임판
            String[][] grid = new String[H][W];

            Tank tank = null;
            for(int i = 0; i < H; i++){
                String[] arr = bf.readLine().split("");
                for(int j = 0; j < arr.length; j++){
                    grid[i][j] = arr[j];
                    if(arr[j].equals("^")){
                        tank = new Tank(i, j, 2);
                    }
                    if(arr[j].equals(">")){
                        tank = new Tank(i, j, 1);
                    }
                    if(arr[j].equals("v")){
                        tank = new Tank(i, j, 0);
                    }
                    if(arr[j].equals("<")){
                        tank = new Tank(i, j, 3);
                    }
                }
            }


            int N = Integer.parseInt(bf.readLine());
            char[] commends = bf.readLine().toCharArray();
            for(char commend : commends){
                processCommand(commend, tank, grid);
            }

            System.out.print("#" + testCase + " ");
            for(int i = 0; i < H; i++){
                for(int j = 0; j < W; j++){
                    System.out.print(grid[i][j]);
                }
                System.out.println();
            }
        }
    }

    static void processCommand(char command, Tank tank, String[][] grid){
        switch(command){
            case 'U':
                tank.move(2, grid);
                break;
            case 'D':
                tank.move(0, grid);
                break;
            case 'L':
                tank.move(3, grid);
                break;
            case 'R':
                tank.move(1, grid);
                break;
            case 'S':
                tank.shoot(grid);
                break;
        }
    }

    static class Tank {
        int x;
        int y;
        int dir;

        Tank(int x, int y, int dir){
            this.x = x;
            this.y = y;
            this.dir = dir;
        }

        void move(int dir, String[][] grid){
            this.dir = dir;
            int nx = x + dxs[dir];
            int ny = y + dys[dir];
            if(inRange(nx,ny,grid.length,grid[0].length) && grid[nx][ny].equals(".")){
                grid[x][y] = ".";
                x = nx;
                y = ny;
            }
            grid[x][y] = symbol();
        }

        void shoot(String[][] grid){
            int nx = x;
            int ny = y;
            while(true){
                nx = nx + dxs[dir];
                ny = ny + dys[dir];
                if(!inRange(nx,ny,grid.length,grid[0].length)) break;
                if(grid[nx][ny].equals("#")) break;
                if(grid[nx][ny].equals("*")){
                    grid[nx][ny] = ".";
                    break;
                }
            }
        }

        String symbol(){
            switch(dir){
                case 0: return "v";
                case 1: return ">";
                case 2: return "^";
                case 3: return "<";
                default: throw new IllegalStateException("Unknown direction: " + dir);
            }
        }
    }

    static boolean inRange(int nx, int ny, int H, int W){
        return nx >= 0 && nx < H && ny >= 0 && ny < W;
    }
}
```

## 처음 접근

main 안에서 x, y, dir을 개별 변수로 관리했다. U, D, L, R마다 방향 변경과 이동 코드를 각각 작성하고 S에서 포탄 경로를 순회했다. 원본은 온라인 정답으로 확인되었다.

## 수정 과정

1. 온라인 통과 원본을 attempts/swea/1873/before-refactor/Solution.java에 그대로 보존했다.
2. 커맨드 처리 부분을 processCommand 함수로 분리했다.
3. x, y, dir을 Tank 객체의 필드로 옮겼다.
4. 중복된 네 방향 이동 처리를 Tank.move로 합쳤다. 이동이 막혀도 방향은 갱신한다.
5. 발사를 Tank.shoot로 분리하고 지도에 표시할 방향 문자는 Tank.symbol로 구한다.
6. 사용하지 않는 HashMap import를 제거했다. 기존 지도 설명 주석과 String[][] 지도, 방향 인덱스 체계는 유지했다.
7. 원본과 리팩토링본, 제출 파일을 각각 독립 컴파일하고 별도 정답 구현과 대조했다.

## 핵심 아이디어

명령 순서대로 전차의 상태와 지도를 갱신한다. 이동은 목적지가 평지일 때만 가능하며, 발사는 벽이나 지도 경계까지 진행한다. Tank가 상태 갱신을 담당하고 명령 분기 함수는 해당 동작을 호출한다.

## 복잡도

- 시간 복잡도: O(HW + N × max(H,W)). 지도 입출력과 최대 N번의 포탄 경로 탐색을 포함한다.
- 공간 복잡도: O(HW + N). 지도와 명령 배열을 저장한다.

## 반례와 경계 조건

- 최소 입력: 2×2 지도와 명령 1개.
- 최대 입력: 20×20 지도와 명령 100개.
- 이동할 수 없어도 전차의 방향은 바뀐다.
- 물은 전차의 이동을 막지만 포탄은 통과한다.
- 포탄은 처음 만난 벽에서 멈추며 벽돌만 평지로 바꾼다.
- 연속 발사, 경계에서 이동·발사, 여러 테스트 케이스의 상태 초기화를 확인한다.
