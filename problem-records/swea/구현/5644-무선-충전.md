## 문제 요약

10×10 영역에서 두 사용자가 매초 이동한다. 각 사용자는 현재 위치에서 범위 안에 있는 무선 충전기를 이용할 수 있으며, 두 사용자가 같은 충전기를 사용하면 그 충전량을 나누어 갖는다. 시작 시점을 포함한 모든 시점에서 두 사용자가 얻을 수 있는 충전량 합의 최댓값을 구한다.

## 입출력

- 입력: 이동 시간 `M`, 충전기 수 `A`, 두 사용자의 이동 정보, `A`개 충전기의 위치·범위·성능이 주어진다.
- 출력: 각 테스트 케이스마다 두 사용자가 얻은 충전량 합의 최댓값을 출력한다.

### 예제 입력

```text
20 3
2 2 3 2 2 2 2 3 3 4 4 3 2 2 3 3 3 2 2 3
4 4 1 4 4 1 4 4 1 1 1 4 1 4 3 3 3 3 3 3
4 4 1 100
7 10 3 40
6 3 2 70
```

### 예제 출력

```text
1200
```

## 최종 Solution 코드

```java
import java.util.*;
public class Solution {
    /**
     * @param moveTime 총 이동 시간 M (입력값 그대로)
     * @param movesA 사용자 A의 M개 이동 방향 (0: 이동 없음, 1: 상, 2: 우, 3: 하, 4: 좌)
     * @param movesB 사용자 B의 M개 이동 방향 (0: 이동 없음, 1: 상, 2: 우, 3: 하, 4: 좌)
     * @param chargers 각 BC의 X, Y, 충전 범위 C, 성능 P (좌표와 입력 순서 그대로)
     * @return 두 사용자가 충전한 양의 합의 최댓값
     */

    // 그룹화 저장
    // 문자열로 충전기를 저장해서 겹칠시 1 -> 13 이렇게 추가형태로 달라붙게
    String[][] map = new String[10][10];
    int[] dxs = {0,-1,0,1,0};
    int[] dys = {0,0,1,0,-1};
    // 각 초마다 최고 효율 충전량
    int[] answerSum;
    // 각 충전기 파워
    int[] chargerPowers;
    // 사용중인 충전기
    boolean[] using;
    public int solution(int moveTime, int[] movesA, int[] movesB, int[][] chargers) {
        answerSum = new int[moveTime + 1];
        chargerPowers = new int[chargers.length + 1];
        using = new boolean[chargers.length + 1];
        for(int i = 0; i < 10; i ++){
            for(int j = 0; j < 10; j++){
                map[i][j] = "";
            }
        }
        // 충전기 정보 초기화
        for(int i = 0; i < chargers.length; i++){
            int x = chargers[i][1] - 1;
            int y = chargers[i][0] - 1;
            int c = chargers[i][2];
            int p = chargers[i][3];
            // 충전기 파워 기록
            chargerPowers[i + 1] = p;
            // 충전기 범위 그룹화로 기록
            makeGroup(c, String.valueOf(i+1), x,y);
        }


        // 시간에 따른 움직임으로 답 기록
        int ax = 0;
        int ay = 0;
        int bx = 9;
        int by = 9;
        getAnswer(ax,ay,bx,by,0);

        for(int i = 0; i < moveTime; i++){
            ax += dxs[movesA[i]];
            ay += dys[movesA[i]];
            bx += dxs[movesB[i]];
            by += dys[movesB[i]];
            getAnswer(ax,ay,bx,by, i + 1);
        }
        int answer = 0;
        for(int i = 0; i < moveTime + 1; i++){
            answer += answerSum[i];
        }

        return answer;
    }

    private void makeGroup(int r, String c, int x, int y){
        Queue<int[]> q = new LinkedList<>();
        boolean[][] visited = new boolean[10][10];
        visited[x][y] = true;
        q.add(new int[]{x,y});

        while(!q.isEmpty()){
            int[] curr = q.poll();
            int currX = curr[0];
            int currY = curr[1];
            map[currX][currY] += c;

            for(int i = 1; i < 5; i++){
                int nx = currX + dxs[i];
                int ny = currY + dys[i];
                if(inRange(nx,ny) && !visited[nx][ny]){
                    if(inGroupRange(r,x,y,nx,ny)){
                        visited[nx][ny] = true;
                        q.add(new int[]{nx,ny});
                    }
                }
            }
        }
    }

    private void getAnswer(int ax, int ay, int bx, int by, int time){
        String[] arrA = map[ax][ay].split("");
        String[] arrB = map[bx][by].split("");
        Arrays.sort(arrA, (a,b) -> chargerPowers[Integer.parseInt(a)] - chargerPowers[Integer.parseInt(b)]);
        Arrays.sort(arrB, (a,b) -> chargerPowers[Integer.parseInt(a)] - chargerPowers[Integer.parseInt(b)]);
        int max = Integer.MIN_VALUE;
        int ap = 0;
        int bp = 0;

        for(int i = 0; i < arrA.length; i++){
            for(int j = 0; j < arrB.length; j++){
                if(!arrA[i].isEmpty()){
                    ap = Integer.parseInt(arrA[i]);
                }
                if(!arrB[j].isEmpty()){
                    bp = Integer.parseInt(arrB[j]);
                }
                if(ap == bp){
                    max = Math.max(max, chargerPowers[ap] / 2 + chargerPowers[bp] / 2);
                } else{
                    max = Math.max(max, chargerPowers[ap] + chargerPowers[bp]);
                }
            }
        }

        answerSum[time] = max;
    }

    private boolean inRange(int nx, int ny){
        return nx >= 0 && nx < 10 && ny >= 0 && ny < 10;
    }

    private boolean inGroupRange(int r, int x, int y, int nx, int ny){
        return Math.abs(x - nx) + Math.abs(y - ny) <= r;
    }


}
```

## 처음 접근

각 충전기의 범위를 BFS로 미리 탐색하여 10×10 `map`의 각 칸에 이용 가능한 충전기 번호를 문자열로 누적했다. 이후 두 사용자의 이동을 시뮬레이션하며 현재 칸의 충전기 후보 조합을 모두 비교해 시점별 최대 충전량을 구했다.

## 처음 틀렸던 점

- 틀린 원인: 기록되지 않음
- 놓친 조건: 기록되지 않음
- 당시 코드 또는 핵심 부분: 해당 없음

## 수정 과정

기록되지 않음.

## 핵심 아이디어

- 충전기마다 맨해튼 거리 안에 포함되는 칸을 미리 그룹화한다.
- 시작 시점과 매 이동 이후 시점마다 두 사용자가 선택할 수 있는 충전기 조합을 모두 비교한다.
- 서로 다른 충전기를 고르면 성능을 합하고, 같은 충전기를 고르면 해당 충전기의 성능만 총합에 반영한다.

### 나중에 다시 풀 때의 개선 방향

현재 풀이는 충전 범위를 BFS로 지도에 미리 기록하고, 문자열 분리와 정렬을 거쳐 후보를 만드는 과정이 다소 복잡하고 비효율적이다. 다음에는 매 시점마다 `충전하지 않음`을 포함해 사용자 A와 B가 선택할 충전기 조합을 직접 완전탐색하고, 각 충전기의 맨해튼 거리 조건을 즉석에서 확인하는 더 단순한 방식으로 다시 풀어본다. 충전기 수가 최대 8개이므로 이 방식도 충분히 빠르다.

## 복잡도

- 시간 복잡도: 충전 범위 전처리 `O(A × 100)`, 이동 시뮬레이션은 대략 `O((M + 1) × (A² + A log A))`
- 공간 복잡도: `O(100 + M + A)`

## 반례와 경계 조건

- 최소 입력: 이동 시간이 0인 경우에도 시작 위치의 충전량을 계산해야 한다.
- 최대 입력: 이동 시간 100, 충전기 8개에서도 모든 시점과 충전기 조합을 확인할 수 있다.
- 실수하기 쉬운 경우: 두 사용자가 같은 충전기를 선택하면 성능을 두 번 더하면 안 된다.
- 실수하기 쉬운 경우: 한 사용자만 충전 가능한 경우와 둘 다 충전할 수 없는 경우도 처리해야 한다.
