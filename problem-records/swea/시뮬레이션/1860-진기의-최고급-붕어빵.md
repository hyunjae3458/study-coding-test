## 문제 요약

M초마다 K개의 붕어빵을 만드는 가게에서 N명의 손님 모두에게 도착 즉시 붕어빵을 줄 수 있는지 판단한다.

## 입출력

- 입력: T, 각 사례의 N M K와 N명의 도착 시각. N,M,K는 1~100, 시각은 0~11,111.
- 출력: `#테스트번호 Possible` 또는 `#테스트번호 Impossible`.
- 현재 작업용 input.txt는 사용자가 변경했으므로 공식 예제는 examples/swea/1860/의 보관본을 사용한다.

### 예제 입력

```text
4
2 2 2
3 4
2 2 2
1 2
2 2 1
4 2
2 2 1
3 2
```

### 예제 출력

```text
#1 Possible
#2 Impossible
#3 Possible
#4 Impossible
```

## 최종 Solution 코드

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.util.Arrays;
import java.util.StringTokenizer;

class Solution {
    public static void main(String args[]) throws Exception {
        BufferedReader bf = new BufferedReader(new InputStreamReader(System.in));
        int T = Integer.parseInt(bf.readLine());

        for (int testCase = 1; testCase <= T; testCase++) {
            StringTokenizer st = new StringTokenizer(bf.readLine());
            // 손님 수
            int N = Integer.parseInt(st.nextToken());
            // 초
            int M = Integer.parseInt(st.nextToken());
            // 개수
            int K = Integer.parseInt(st.nextToken());

            int[] reserve = new int[N];
            st = new StringTokenizer(bf.readLine());
            for(int i = 0; i < N; i++){
                reserve[i] = Integer.parseInt(st.nextToken());
            }
            // 먼저 온 사람으로 정렬
            Arrays.sort(reserve);
            int lastPerson = reserve[N- 1];
            int[] visited = new int[lastPerson + 1];
            for(int r : reserve){
                visited[r] += 1;
            }

            int time = 1;
            int currCnt = 0;
            int answer = 0;
            while(time <= lastPerson){
                if(time % M == 0){
                    currCnt += K;
                }
                while(visited[time] > 0){
                    if(currCnt <= 0){
                        break;
                    }
                    currCnt -= 1;
                    answer += 1;
                    visited[time] -= 1;
                }
                time += 1;
            }
            if(answer == N){
                System.out.println("#" +testCase + " Possible");
            } else{
                System.out.println("#" +testCase + " Impossible");
            }
        }
    }
}
```

## 처음 접근

도착 시각을 정렬하고, 각 시각에 방문할 손님 수를 visited 배열에 저장했다. 1초씩 시간을 진행하며 생산량을 재고에 더하고 해당 시각 손님에게 제공한다. 제공한 총인원이 N인지 확인한다.

## 핵심 아이디어

시간별 생산과 방문을 직접 시뮬레이션한다. 같은 시각에는 생산을 먼저 처리한다. 손님에게 제공한 수를 누적해 전원에게 제공했는지 판단한다.

## 복잡도

마지막 도착 시각을 L이라 한다.

- 시간 복잡도: O(N log N + L). 정렬, 시간 순회 및 총 N명 이하의 제공 처리.
- 공간 복잡도: O(N + L). 예약 배열과 시간별 방문자 배열.

## 반례와 경계 조건

- 최소 입력: N=M=K=1, 도착 시각 0 또는 1.
- 최대 입력: N=100, 마지막 도착 시각 11,111.
- 같은 시각에 여러 손님이 도착하는 경우와 생산 완료 시각에 도착하는 경우.
- 0초 손님은 반복문에서 제공되지 않아 최종 answer가 N보다 작다.
- 재고 부족으로 제공하지 못한 손님은 이후 시각에 다시 처리하지 않는다.

## 한 줄 요약
