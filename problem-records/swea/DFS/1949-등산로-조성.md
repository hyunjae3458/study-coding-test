## 문제 요약

N×N 지형에서 가장 높은 봉우리 중 하나를 시작점으로 선택한다. 상하좌우로 현재
지형보다 낮은 곳으로만 이동할 수 있으며, 한 곳을 정해 최대 K만큼 지형을 깎을 수
있다. 지형을 깎은 뒤에도 현재 지형보다 낮아야 하며, 만들 수 있는 가장 긴
등산로의 길이를 구한다. 지형은 필요한 경우 1보다 작게 만들 수 있다.

- 입력: 첫 줄에 테스트 케이스 수 T가 주어진다. 각 테스트 케이스마다 지도의 크기 N, 최대 공사 가능 깊이 K, N×N 지형 높이가 주어진다.

## 최종 Solution 코드

~~~java
import java.util.*;
public class Solution {
    /**
     * @param size 지도의 한 변의 길이 N (입력값 그대로)
     * @param maxCutDepth 최대 공사 가능 깊이 K (입력값 그대로)
     * @param map N×N 지형 높이 지도 (입력 순서와 값 그대로)
     * @return 만들 수 있는 가장 긴 등산로의 길이
     */
    int[][][] dp;
    int[] dxs = {1,0,-1,0};
    int[] dys = {0,1,0,-1};
    int N;
    boolean[][] visited;
    int answer = 0;
    public int solution(int size, int maxCutDepth, int[][] map) {
        visited = new boolean[size][size];
        N = size;
        dp = new int[N][N][maxCutDepth + 1];
        int highest = 0;
        for(int i = 0; i < N; i++){
            for(int j = 0; j < N; j++){
                highest = Math.max(highest, map[i][j]);
            }
        }

        // q초기화
        for(int i = 0; i < N; i++){
            for(int j = 0; j < N; j++){
                if(highest == map[i][j]){
                    visited[i][j] = true;
                    dfs(i,j,1,false,map[i][j],map,maxCutDepth);
                    visited[i][j] = false;
                }
            }
        }

        return answer;
    }

    private void dfs(int x, int y, int length, boolean used, int currHeight, int[][] map, int K) {
        answer = Math.max(answer, length);

        for (int d = 0; d < 4; d++) {
            int nx = x + dxs[d];
            int ny = y + dys[d];

            if (!inRange(nx, ny) || visited[nx][ny]) {
                continue;
            }

            // 공사 없이 이동 가능
            if (map[nx][ny] < currHeight) {
                visited[nx][ny] = true;
                dfs(nx, ny, length + 1, used, map[nx][ny], map, K);
                visited[nx][ny] = false;
            }

            // 아직 공사를 안 했고, 깎으면 이동 가능
            else if (!used && map[nx][ny] - K < currHeight) {
                visited[nx][ny] = true;

                // 필요한 만큼만 깎아서 현재 높이보다 1 낮게 설정
                dfs(nx, ny, length + 1, true, currHeight - 1, map,K);

                visited[nx][ny] = false;
            }
        }
    }

    private boolean inRange(int nx, int ny){
        return nx >= 0 && nx < N && ny >= 0 && ny < N;
    }
}
~~~

## 처음 접근

### 1차 시도: 3차원 상태 DP + BFS

처음에는 각 상태를 좌표, 현재까지의 거리, 공사 사용 여부 또는 공사 깊이,
현재 높이로 표현하는 BFS를 시도했다. Node에 좌표, 거리, 공사 상태, 현재 높이를
담고, dp[x][y][k]에 특정 공사 상태로 해당 지점에 도달했을 때의 최대 거리를
저장했다. 가장 높은 봉우리들을 큐에 넣어 상하좌우로 확장했다.

공사를 아직 하지 않은 상태에서는 다음 칸을 0부터 K까지 각각 깎아 보고,
공사 후 높이가 현재 높이보다 낮으면 해당 상태를 큐에 넣는 방식이었다.

1차 시도의 핵심 코드는 다음과 같다.

~~~java
class Node{
    int x;
    int y;
    int dis;
    int used;
    int currHeight;
    Node(int x, int y, int dis, int used, int currHeight){
        this.x = x;
        this.y = y;
        this.dis = dis;
        this.used = used;
        this.currHeight = currHeight;
    }
}

int[][][] dp;
Queue<Node> q = new LinkedList<>();

if(used == 0){
    for(int j = 0; j < maxCutDepth + 1; j++){
        int nextHeight = map[nx][ny] - j;
        if(nextHeight < currHeight){
            if(dp[nx][ny][j] < dis + 1){
                dp[nx][ny][j] = dis + 1;
                q.add(new Node(nx,ny,dis + 1,j,nextHeight));
            }
        }
    }
}
~~~

### 2차 시도: DFS + 백트래킹

경로마다 방문한 칸을 관리해야 하므로 DFS로 전환했다. DFS의 재귀 경로마다
visited를 사용하고, 재귀 호출이 끝나면 방문 표시를 되돌렸다. 공사 여부는
boolean으로 관리하고, 실제 지도를 수정하는 대신 공사한 다음 칸의 현재 높이를
currHeight - 1로 전달했다.

## 처음 틀렸던 점

### 1차 시도

- 좌표와 공사 상태만으로는 한 경로에서 이미 방문한 칸을 다시 방문하지 않아야 한다는 조건을 경로별로 관리하기 어려웠다.
- dp[x][y][k]는 공사 깊이만 저장하지만, 공사를 어느 지점에서 했는지에 따라 현재 경로의 높이와 이후 이동 가능성이 달라질 수 있어 상태를 합치는 데 한계가 있었다.
- System.out.println(Arrays.deepToString(dp)); 디버그 출력도 포함되어 있었다.

### 2차 시도

- DFS로 변경한 뒤에도 처음에는 최고점에서 DFS를 시작할 때 시작 칸을 visited에 표시하지 않았다.
- 그 결과 DFS 경로가 출발한 최고점으로 다시 들어갈 수 있었다.
- 최고점 DFS 호출 전후에 다음 처리를 추가해 해결했다.

~~~java
visited[i][j] = true;
dfs(i,j,1,false,map[i][j],map,maxCutDepth);
visited[i][j] = false;
~~~

## 수정 과정

1. 3차원 상태 DP+BFS에서 경로별 방문 처리가 가능한 DFS+백트래킹으로 전환했다.
2. 가장 높은 모든 봉우리에서 DFS를 시작하도록 했다.
3. DFS 내부에서 낮은 지형은 그대로 이동하고, 아직 공사하지 않았으며 K 이내로 깎을 수 있는 지형은 현재 높이보다 1 낮게 만든 것으로 처리했다.
4. 재귀 호출 전후에 다음 칸의 visited를 표시하고 해제했다.
5. 최고점 자체도 DFS 시작 시 방문 처리하고, DFS가 끝나면 해제하도록 수정했다.
6. 디버그용 DP 출력은 최종 코드에서 제거했다.
7. 수정된 풀이를 SWEA에 제출해 온라인 정답을 확인했다.

## 핵심 아이디어

- 지도의 최댓값을 구하고 그 높이를 가진 모든 칸에서 탐색을 시작한다.
- 등산로는 같은 칸을 다시 방문할 수 없으므로 DFS 경로별로 visited를 관리한다.
- 현재 칸보다 낮은 칸은 바로 이동한다.
- 아직 공사를 사용하지 않았고 다음 높이 - K < 현재 높이이면 다음 칸을 현재 높이보다 1 낮게 만든 뒤 한 번 이동한다.
- 공사한 실제 지도 값을 바꾸지 않고 재귀 인자로 현재 높이를 전달해 백트래킹 복구를 단순화한다.
- 각 경로의 길이 최댓값을 갱신한다.

## 복잡도

- 시간 복잡도: 최고점 개수를 H라고 할 때, 방문 경로를 모두 탐색하는 최악의 경우 O(H × 4^(N²))이다. H는 최대 5이다.
- 공간 복잡도: visited와 재귀 호출에 O(N²), 코드에 남아 있는 dp 배열에 O(N²K)가 필요하므로 전체는 O(N²K)이다.

## 반례와 경계 조건

- 최소 크기 N=3인 지도와 최고점이 여러 개인 경우를 확인한다.
- 최대 크기 N=8, 최대 공사 깊이 K=5인 경우를 확인한다.
- 다음 지형과 현재 지형의 높이 차이가 정확히 K이면 K만큼 깎아도 같아지므로 이동할 수 없다.
- 공사는 정확히 K만큼이 아니라 1부터 K까지 필요한 만큼 할 수 있다.
- 깎은 지형이 1보다 작아지는 경우도 허용된다.
- 시작점인 최고 봉우리는 공사 대상이 아니며, 여러 최고점은 각각 시작점으로 탐색해야 한다.
- 시작 봉우리도 방문 칸이므로 DFS 시작 직전에 표시하고 탐색 후 해제해야 한다.

## 한 줄 요약

최고점마다 DFS를 시작하고 경로별 visited와 한 번의 지형 공사를 백트래킹으로 관리하되, 시작 봉우리도 반드시 방문 처리한다.
