## 문제 요약

각 칸의 숫자가 해당 도로를 복구하는 데 필요한 시간을 나타내는 N×N 지도에서, 좌상단 (0, 0)부터 우하단 (N-1, N-1)까지 상하좌우로 이동할 때 필요한 최소 복구 시간을 구한다. 출발 칸의 복구 시간은 합산하지 않고, 이동해서 들어가는 칸의 복구 시간을 누적한다.

## 입출력

- 입력: 첫 줄에 테스트 케이스 수 T가 주어진다. 각 테스트 케이스마다 지도 크기 N과 숫자가 공백 없이 이어진 N개의 지도 행이 주어진다.
- 출력: 각 테스트 케이스마다 `#테스트번호 최소복구시간`을 출력한다.

### 예제 입력

```text
2
4
0100
1110
1011
1010
6
011001
010100
010011
101001
010101
111010
```

### 예제 출력

```text
#1 2
#2 2
```

## 최종 Solution 코드

```java
import java.util.*;
public class Solution {
    /**
     * @param size 지도의 크기 N (입력값 그대로)
     * @param map 각 칸의 복구 시간인 N×N 지도 (입력 숫자 그대로)
     * @return (0, 0)에서 (N-1, N-1)까지 이동할 때 필요한 최소 복구 시간
     */
    class Node{
        int x;
        int y;
        int cost;
        public Node(int x, int y, int cost){
            this.x = x;
            this.y = y;
            this.cost = cost;
        }
    }
    int N;
    int[] dxs = {1,0,-1,0};
    int[] dys = {0,1,0,-1};
    public int solution(int size, int[][] map) {
        N = size;
        PriorityQueue<Node> q = new PriorityQueue<>((a,b) -> Integer.compare(a.cost, b.cost));
        int[][] dp = new int[N][N];

        for(int[] d : dp){
            Arrays.fill(d, Integer.MAX_VALUE);
        }

        dp[0][0] = 0;
        q.add(new Node(0,0,0));

        while(!q.isEmpty()){
            Node curr = q.poll();
            int x = curr.x;
            int y = curr.y;
            int cost = curr.cost;
            if(dp[x][y] < cost) continue;

            for(int i = 0; i < 4; i++){
                int nx = x + dxs[i];
                int ny = y + dys[i];
                if(inRange(nx,ny)){
                    if(dp[nx][ny] > cost + map[nx][ny]){
                        dp[nx][ny] = cost + map[nx][ny];
                        q.add(new Node(nx,ny,dp[nx][ny]));
                    }
                }
            }
        }
        return dp[N-1][N-1];
    }

    private boolean inRange(int nx ,int ny){
        return nx >= 0 && nx < N && ny >= 0 && ny < N;
    }
}
```

## 처음 접근

지도의 각 칸을 정점으로, 상하좌우 이동을 간선으로 생각했다. 다음 칸의 복구 시간을 간선 비용처럼 누적하고, 우선순위 큐에서 현재까지의 비용이 가장 작은 칸부터 꺼내는 다익스트라 방식으로 최단 비용을 구했다.

## 처음 틀렸던 점

해당 없음.

## 수정 과정

오답 수정 이력 없이 현재 다익스트라 풀이로 공식 예제를 통과했고 SWEA 온라인 채점에서 정답을 받았다.

## 핵심 아이디어

- `dp[x][y]`에 시작점부터 (x, y)까지 도달하는 최소 복구 시간을 저장한다.
- 시작점의 비용은 0으로 두고 우선순위 큐에 넣는다.
- 현재 비용에 다음 칸의 복구 시간을 더한 값이 기존 최소 비용보다 작을 때만 갱신한다.
- 우선순위 큐에서 꺼낸 비용이 이미 기록된 최소 비용보다 크면 오래된 항목이므로 건너뛴다.

## 복잡도

- 시간 복잡도: 정점 수가 N², 간선 수가 최대 4N²이므로 `O(N² log N²)`
- 공간 복잡도: 지도, 최소 비용 배열, 우선순위 큐를 사용하므로 `O(N²)`

## 반례와 경계 조건

- 최소 크기의 지도에서는 시작점과 도착점이 같을 수 있으며 결과는 0이다.
- 시작 칸의 복구 시간은 비용에 더하지 않는다.
- 먼저 방문한 칸이라도 더 작은 비용의 경로가 발견되면 다시 갱신해야 한다.
- 같은 칸에 대한 오래된 우선순위 큐 항목을 그대로 확장하지 않도록 현재 비용과 `dp`를 비교한다.
- 지도 행은 숫자 사이에 공백이 없으므로 문자별로 숫자로 변환해야 한다.
- N이 최대 100이어도 `Integer.MAX_VALUE`에 실제 비용을 더하지 않도록 도달한 정점만 큐에서 처리한다.

## 한 줄 요약

각 칸까지의 최소 복구 시간을 저장하고, 다음 칸의 복구 시간을 가중치로 사용하는 다익스트라로 우하단까지의 최소 비용을 구한다.
