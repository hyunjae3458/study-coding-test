# 과제 테스트 연습

각 문제의 `Main.java`에서 표준 입력을 읽고 표준 출력으로 답을 출력합니다.
입력 파싱만 준비했으며 풀이와 출력은 직접 작성합니다. 기존 `src/`의 백준 풀이는 보존했습니다.
문제 출처는 사용자가 제공한 과제 설명이며, 공식 문제 번호·링크·난이도는 제공되지 않았습니다.

## 파일과 실행

### IntelliJ에서 바로 확인

상단 실행 구성에서 다음 항목을 선택합니다. 목록이 갱신되지 않으면 프로젝트를 다시 엽니다.

- `과제 1 - 전체 예제 채점`: ▶ 실행하면 1번 예제를 모두 비교합니다.
- `과제 2 - 전체 예제 채점`: ▶ 실행하면 2번 예제를 모두 비교합니다.
- `과제 1 - 예제 1 실행 및 디버깅` 등의 구성: 해당 예제 파일을 자동으로 표준 입력에 연결합니다.
  `Main.java` 줄 번호 옆에 중단점을 찍고 Debug(벌레 아이콘)를 누르면 변수와 실행 흐름을 확인할 수 있습니다.

전체 예제 채점은 테스트마다 별도 프로세스를 사용하므로 중단점 확인은 **예제별 실행 및 디버깅** 구성을 사용합니다.
컴파일 오류는 실행 전 Build 창에 표시됩니다. 오류 위치를 클릭하면 해당 코드로 이동합니다.
사용자 입력으로 확인하려면 문제 폴더의 `input.txt`를 수정하고 예제 1 구성을 실행합니다.
비교도 하려면 `output.txt`에 기댓값을 작성합니다.

두 문제는 별도 Java 모듈이므로 같은 `Main` 클래스명을 그대로 사용합니다.
풀이 파일에는 채점 코드를 추가하지 않았으며 `support/ExampleCheck.java`가 비교를 담당합니다.
실행 구성의 입력 연결은 [IntelliJ Application 설정](https://www.jetbrains.com/help/idea/run-debug-configuration-java-application.html)의 Redirect input 기능을 사용합니다.

| 문제 | 풀이 파일 | 제공 예제 출력 |
| --- | --- | --- |
| 1. 버스 운행 수익 (임시 제목) | `01-bus/Main.java` | 21, 14, 45 |
| 2. 창고에서 물건 가져오기 | `02-warehouse/Main.java` | 250, 180 |

프로젝트 루트에서 1번을 실행합니다.

```bash
javac -encoding UTF-8 -d out/assignment-01 assignments/01-bus/Main.java
java -cp out/assignment-01 Main < assignments/01-bus/input.txt
```

2번 실행:

```bash
javac -encoding UTF-8 -d out/assignment-02 assignments/02-warehouse/Main.java
java -cp out/assignment-02 Main < assignments/02-warehouse/input.txt
```

전체 예제 비교 (Python 3 및 JDK 필요):

```bash
python3 assignments/check_examples.py
```

명령 뒤에 `1` 또는 `2`를 붙이면 해당 문제만 확인합니다.
각 문제의 `input.txt`, `output.txt`는 예제 1이며 나머지는 해당 `examples/`에 있습니다.
채점기는 임시 폴더에 각각 컴파일하고 예제마다 별도 프로세스를 실행합니다.
10초 제한은 로컬 실행 보호용이며 과제의 공식 시간 제한은 제공되지 않았습니다.
아직 풀이가 비어 있어 예제 비교는 실패하는 것이 정상입니다.
이 스크립트는 제공된 예제만 확인하며, 확장 채점이나 정답 기록을 수행하지 않습니다.

## 1번 입력과 규칙

첫 줄은 `R K N`, 둘째 줄은 줄에 선 순서대로 일행의 인원 `g₁ ... gₙ`입니다.
`R`은 운행 횟수, `K`는 버스 정원, `N`은 일행 수입니다.

- 1 ≤ R ≤ 1,000,000
- 1 ≤ K ≤ 10,000
- 1 ≤ N ≤ 100
- 1 ≤ gᵢ ≤ K

일행은 나눠 탈 수 없으며 앞에서부터 탑승합니다. 다음 일행이 정원을 초과하면 탑승을 마칩니다.
매 운행에서 각 일행은 최대 한 번 탑승하며, 탑승한 일행들은 기존 순서대로 줄 뒤로 이동합니다.
탑승 인원 1명당 수익은 1유로이며, 총 R회 운행 수익을 정수 하나로 출력합니다.
이는 제공된 예제 설명을 기준으로 정리한 규칙입니다.

## 2번 입력과 규칙

첫 줄은 `N K P`, 이후 N줄에 각 상자의 물건 가치 K개가 위에서부터 순서대로 주어집니다.
각 상자에서는 위에서부터 순서대로 꺼내야 합니다.
전체에서 정확히 P개를 꺼냈을 때 최대 가치 합을 정수 하나로 출력합니다.

- 1 ≤ N ≤ 50
- 1 ≤ K ≤ 30
- 1 ≤ P ≤ N × K
- 1 ≤ vᵢ ≤ 100

제공된 제한에는 `1 ≤ T ≤ 50`이 있지만 입력 설명에는 T가 없습니다.
현재는 설명과 예제에 따라 **T 없이 단일 테스트 입력**으로 세팅했습니다.
`Case #...` 같은 접두어도 명시되지 않아 출력은 정수 하나입니다.
실제 제출 입력이 T로 시작한다면 테스트 반복과 출력 형식을 해당 명세에 맞춰 변경해야 합니다.
